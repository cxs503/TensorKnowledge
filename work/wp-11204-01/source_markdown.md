# FEM 弹塑性本构（von Mises J2）与 3D 混合模式 cohesive 单元：CT / 三点弯曲验证

**节点** p273w3-n01-fem-elastoplastic-cohesive ｜ **仓** TensorPhysics ｜ **模块** `src/tensorphysics/fem_nonlinear/` ｜ **分支** `agent/m9422`

## ① 案例介绍（物理背景 / 几何 / 参数）

线弹性断裂评估无法给出真实材料的失效载荷与峰后软化段。本节点把平台的结构
完整性能力从「线弹性 + 解析 K」推进到「弹塑性本构 + 界面损伤」：

* **von Mises J2 弹塑性**：小应变径向返回映射 + 算法一致切线，用于紧凑拉伸
  试样（CT）的极限载荷与 J 积分；
* **3D 混合模式 cohesive**：双线性牵引-分离律（模式 I/II/III）+ 扩展
  Benzeggagh-Kenane 准则，用于三点弯曲梁（SE(B)）的全过程载荷-位移曲线。

几何与材料（ASTM E399/E1820 标准比例，SI 单位）：

| 量 | CT | SE(B) |
|---|---|---|
| 宽度 W | 50 mm | 25 mm |
| 厚度 B | 25 mm | 25 mm |
| 初始裂纹 a/W | 0.50 | 0.50 |
| 跨距 S | — | 4W = 100 mm |
| 弹性常数 | E = 200 GPa, nu = 0.3 | 同左 |
| 塑性 | sigma_y = 1000 MPa (小范围屈服) / 350 MPa (弹塑性), 线性硬化 H = 20 / 10 GPa | 同左 |
| 界面 | — | K_n=K_s=K_t=1e16 Pa/m, t_n0=600 MPa, G_Ic=2000 J/m² |

界面参数满足 `K >> sigma_max^2/(2G_c)`（delta_0/delta_f = 0.009），粘聚区长度
约 0.5 mm，远小于韧带 12.5 mm，处于小范围桥接极限（可对照 LEFM）。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **本构层** `j2_plasticity.py`：小应变径向返回映射（线性 / Swift 等向硬化），
   一致切线 `C_ep = K 1x1 + 2G alpha I_dev - 2G[3G/(3G+H') - (1-alpha)] NxN`，
   以中心差分逐分量校核（相对误差 < 1e-6），并提供批量向量化版本供 FE 装配。
2. **界面层** `cohesive3d.py`：双线性牵引-分离律 + 二次应力起裂判据 + 三模式扩展 BK
   `G_c = G_Ic + (G_shear,c - G_Ic)(G_shear/G_T)^eta`，
   `G_shear,c = G_IIc + (G_IIIc - G_IIc) G_III/G_shear`；
   8 节点（4 对节点）界面单元、2x2 高斯积分、数值一致切线、拉压不对称（压缩不损伤）。
3. **求解层** `plane_strain_fem.py`：平面应变 Q4 双线性单元，Newton-Raphson 带回溯
   线搜索，载荷 / 位移控制，对称面 mode-I 粘聚弹簧线，等效域积分（EDI）J 积分
   （裂纹扩展方向可配 x/y）。裂纹用**节点复制完整模型**离散：半模型的对称线落在
   EDI 积分域内会引入面项污染（实测偏差 -50% / -82%），完整模型下该面项恒为零。
4. **锚点层** `anchors.py`：ASTM E399 CT / SE(B) 几何因子、`J = K^2(1-nu^2)/E`、
   ASTM E1820 eta 因子（CT：`eta_pl = 2 + 0.522(1-a/W)`）。
5. **判据层** `verification.py` + `scripts/m9422_run_verification.py`：一键产出全部
   数字（`artifacts/m9422/verification.json`、`acceptance.json`），报告零手抄。

## ⑤ 注意点（踩过的坑 / 局限 / 适用域）

1. **半模型的 EDI 陷阱**：裂纹面与对称面重合时，半模型的对称线落在积分域内部，
   域积分缺少沿对称线的面项，实测 J 偏小 50%（CT）/ 82%（SE(B)）。本实现改为节点
   复制完整模型，该面项恒为零；`j_integral(symmetry_factor=2)` 仅保留给必须用半模型的
   场合，并在 docstring 中写明成立条件。
2. **裂纹扩展方向**：SE(B) 裂纹沿 +y 生长，EDI 公式须换成 `[σ_ij u_j,2 - W δ_2i] q,i`
   （`crack_axis=1`）；用错轴向会得到近乎为零的 J。
3. **粘聚区参数自洽**：双线性律要求 `K_n >> σ_max²/(2G_Ic)`，否则 δ0 ≈ δf，界面退化为
   「瞬间全损」——初版取 K_n = 1e14 时峰值载荷偏低 58%。
4. **snap-through 与步长**：裂尖首个界面点起裂时刚度突降，位移控制同样会失稳；
   采用失败步折半（bisection）自动细分后 60 步全部收敛。
5. **塑性迭代极限环**：Gauss 点在一次 Newton 循环内往返塑性加载/弹性卸载时，一致切线
   不再保证下降方向，需回溯线搜索。
6. **Q4 弯曲精度**：SE(B) 以弯曲为主，双线性四边形剪切锁死导致收敛阶偏低，工程精度需
   ≥48×40 网格；Q8 / 减缩积分未实现。
7. **适用域**：小应变、单调加载、无接触、结构化网格；未含几何非线性、循环塑性
   （随动硬化/棘轮）、界面摩擦与率效应。
