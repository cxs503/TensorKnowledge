# Invented pendulum dataset: reproducible arithmetic, not an experiment

**Status:** worked-example draft · **Version:** 0.1.0 · **Last source check:** 2026-11-23

This companion to [Scientific Thinking: From Observation to Explanation](README.md) teaches how to work from a timing table to a model comparison. **All 12 timing values were deliberately invented for instruction.** They are **not** measurements, were **not** obtained from a physical experiment, and were **not** generated by a validated physical simulator. Their values cannot validate a physics law, estimate local gravitational acceleration, or establish measurement uncertainty. The accompanying script only reproduces arithmetic.

## Files and repeatability

- [illustrative-pendulum.csv](illustrative-pendulum.csv) — four lengths, three made-up 10-cycle times per length, with explicit origin labels.
- [analyze_illustrative_pendulum.py](analyze_illustrative_pendulum.py) — standard-library Python analysis; no external package or random seed needed.

From the repository root:

```bash
python flagship-tutorials/01-scientific-thinking/analyze_illustrative_pendulum.py
```

Inputs are decimal seconds for **ten full cycles**, not one period. The invented lengths are metres from the pivot to the bob centre. The origin column prevents mistaking these values for learner measurements. The file contains no instrument, location, operator, actual release angle, calibration, timestamp or raw video, because no observation took place.

## What the arithmetic does

For each length, divide each 10-cycle time by 10 and average its three periods:

```text
mean period = (trial_1 + trial_2 + trial_3) / 30
```

Square each mean period and fit the **unweighted ordinary-least-squares** relation `y = a*L + b`, where `y = mean period squared`, fitting **both** `a` and `b`. The fit does not force the intercept to zero.

| Length L (m) | Mean period T (s) | T² (s²) | Residual of T² (s²) |
|---:|---:|---:|---:|
| 0.25 | 1.013000 | 1.026169 | +0.006712 |
| 0.40 | 1.272333 | 1.618832 | -0.011983 |
| 0.55 | 1.498667 | 2.246002 | +0.003829 |
| 0.70 | 1.689667 | 2.854973 | +0.001442 |

The script prints the unrounded calculation and these rounded display values. In this invented table:

- fitted slope `a = 4.075722 s²/m`;
- fitted intercept `b ≈ 0.000526 s²`;
- formal quantity `4π²/a ≈ 9.686239 m/s²`.

**Do not report the last number as local gravity.** The ideal small-angle simple-pendulum model gives `T² = (4π²/g)L`, so the conversion shows what a slope *would imply if the model and measurement assumptions held*. Here the input numbers are made up, so the conversion has no observational force. The conventional reference 9.80665 m/s² is not a universal measured local value.

### How to read residuals

A residual is observed (here: invented) `T²` minus fitted `T²` at the same length. Residuals of mixed sign do not prove that the model is correct. With only four constructed points, this example does not justify an uncertainty interval, significance test, model selection, or real-world precision claim. The fitted intercept being numerically near zero is **not** proof that the measurement setup lacks offsets; in fact no setup was measured.

### Exercises to complete without an agent

1. Calculate the three periods for `L = 0.40 m`; show their average and square it. State the units of every quantity.
2. Recompute the line fit from the `L, T²` pairs, allowing a free intercept. Independently check one predicted value and its residual.
3. Change a **single invented trial** by +0.30 s (for ten cycles), recalculate, and explain the effect on slope, intercept and residuals.
4. Explain why fitting with a free intercept versus forcing `b=0` changes the inference. Which experimental details would help test whether an offset is real?
5. Design a real-data protocol: instrument and calibration details, ruler resolution, bob-centre definition, release-angle method, counting/timing conventions, repeats, raw-data retention, and ways to examine bias and uncertainty.

**Independent evaluation:** require hand-checks for one period, one mean, one residual and one conversion of units before showing the script output. A learner must distinguish illustrative arithmetic from empirical evidence to meet the evidence-and-judgment outcomes.

## What must happen before this becomes a validated laboratory example

- Collect **real raw timings** from a documented physical setup, including excluded readings and a reason for each exclusion; never replace the illustrative CSV without changing provenance.
- Complete separate instrument/geometry and uncertainty assessments; do not infer uncertainty solely from within-length repeats or invented numbers.
- Perform independent physics/measurement review and computational reproducibility review.
- Pilot the activities with actual learners, collect confusion and task-performance records, and revise the teaching materials.

Each review is **pending**, not completed. A computer successfully executing the script would prove only reproducible arithmetic on invented input.
