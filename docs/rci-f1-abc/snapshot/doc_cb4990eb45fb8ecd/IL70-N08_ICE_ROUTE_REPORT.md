## ① 案例介绍

**物理背景**：冰区（北极东北航道/喀拉海扇形航段）船舶的航速受海冰厚度支配，冰阻力与敞水阻力对航速的依赖不同，
因此“燃油最省”与“时间最短”是两条不同的航线——这正是气象/冰情导航的商业价值所在。本节点把
**冰情场（预报时效可插值）→ Lindqvist 冰阻力场 → 图搜索 → 平滑 → 复核** 全链条做成可复算的确定性模块，
并以三条可机器裁决的算例给出精度证据。

**船型参数（参考 PC6 级中型冰区加强船，几何先验校验通过）**

| 参数 | 值 | 说明 |
|---|---|---|
| Lpp / Lwl / B / T | 120.0 / 126.0 / 24.0 / 8.5 m | 冰区加强船主尺度 |
| Cb / 排水体积 | 0.72 / 17625.6 m³ | 几何自洽：Cb 校验通过 (偏差=0.00%) |
| 敞水设计点 | 16.0 kn @ 850.0 kN | 敞水阻力二次律 R_ow = R_design·(v/v_open)² |
| 冰区限速上限 h_max | 1.5 m | v_max(h)=v_open(1-h/h_max)；h≥h_max 视为不可航 |
| 首部半角 / 柱角 | 22° / 28° | Lindqvist 弯曲/清除项 |

**算例（冰况为参数化情景，非实测数据）**

| 算例 | 网格 | 冰情 | 用途 |
|---|---|---|---|
| (a) 均匀冰场 | 0.1°×0.1°，51×311 | h = 0.5 m 常数 | 最优路径 = 大圆（解析基准） |
| (b) 冰脊屏障 | 0.1°×0.1°，51×311 | 背景 0.4 m + 近南北冰脊带（峰 2.2 m ≥ h_max） | 绕避不可航冰脊核 |

| (e) 效率基准 | 0.1°×0.1°，100×100 | h = 0.6 m 常数 | Dijkstra < 1 s |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **海域网格化**：`GeoGrid(lat_min, lon_min, lat_max, lon_max, dlat, dlon)`，缺省 Δ=0.1°；
   中纬 0.1° 纬向 = 11.11 km，经向随纬收缩（70°N 处 ≈ 3.8 km）——**单元各向异性**是后续必须处理的数值事实。
2. **冰情场**：`IceField` 支持多预报时效切片（`lead_hours`），空间双线性 + 时间线性插值；
   特征构造器 `RidgeBand`（有限长冰脊带，垂直向 Gaussian）、`IcePatch`（超高斯 h=peak·exp(-(r/R)^power)，power≥4 近平顶）。
3. **冰阻力场**：逐网格调用 Lindqvist(1989)（复用 `api.ice.formulas.calc_lindqvist` 的校准系数，向量化镜像）；
   单点标量实现与向量化实现逐项对账（相对差 < 1e-6，见测试 `test_vectorized_lindqvist_matches_scalar`）。
4. **航速限制**：`v_max(h) = v_open·(1 - h/h_max)`，h ≥ h_max 的单元标记为不可航（图里直接删除该节点）。
5. **图搜索**：节点 = 网格点；边 = 8 邻域（可选 16）；边权 = 燃油 `Σ R̄·d`（MJ=kN·km）或 时间 `Σ d/v`（h）；
   `Dijkstra`（heapq + 纯 Python 邻接表）与 `A*`（可采纳启发式：大圆余距 × 图内最小单位代价，实测与 Dijkstra 同代价）。
6. **任意角拉直（any-angle / string-pulling）**：网格解受 8 邻域方向量化影响（本算例 +15.34%），
   逐段用“大圆段可行且代价不增”作替换，把航线拉紧到连续平面最优附近（代价单调不增，见 `test_tauten_is_monotone_and_preserves_endpoints`）。
7. **平滑**：**球面**三次 clamped B 样条（在单位向量上做 de Boor，再归一化）——保端点插值、C² 连续，
   且**控制点共大圆时曲线严格落在大圆上**（否则平滑会破坏“均匀冰场=大圆”这一物理结论）。
   双守卫：全程 h < h_max，且燃油/时间代价相对原航线劣化 ≤ 1%；全部候选失败则回退原航线（不静默放行）。
8. **复核与出图**：逐点核 v ≤ v_max(h)、冰厚、不可航点、航向变化；`matplotlib` 出 4 张图。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **经纬网格各向异性是头号数值坑**：0.1° 单元在 74°N 处纬向 11.11 km、经向仅 3.06 km，
   8 邻域在**地面距离空间**里只剩下 0°/75°/90° 三个可用方向 → 纯网格最优路径比大圆长 15.34%。
   这不是“搜索不对”，而是方向量化；本模块用 any-angle 拉直消除（1.75e-06%），并在报告中把两个数字都列出，不隐瞒。
2. **`_shift` 方向语义必须“取目标邻点”**：初版写成 `out[i+di]=a[i]`，边权把反向格点的阻力读进来，同质场看不出来、异质场会系统偏移（已修，见提交说明）。
3. **长航段不能只取端点采样**：拉直后的航段可达数百 km，若只用端点冰厚估航速，会把穿厚冰的航段算成 12.8 kn（真值 1.07 kn）。
   本模块 `_polyline_costs/_segment_metrics` 一律按 4 km 步长沿大圆密集采样；`smooth_path` 入口先把折线加密到 ≥100 点。
4. **平滑会切角**：B 样条在冰脊尖端切内角可把最大冰厚从 0.4 m 抬到 0.89 m（偏距 16.3 km）。
   因此设“可航性 + 冰情裕度 + 代价不劣化 ≤1%”三守卫，失败则回退原航线并置 `fallback_to_raw=True`。
   本算例平滑后越界量 0.000000 m/s（满足判据）。
5. **拉直是贪心**（几何递减探测 + 只接受不增代价的替换）：代价单调不增但不保证全局最优，极端窄通道场景可能停在次优解。
6. **v_max(h) 的线性形式是任务书给定关系**（工程近似，源自冰级冰中航速能力），不是从破冰力学推导；h≥h_max 直接判不可航也是保守工程约定。
7. **风只按 R_AW = ½ρ_a·C_AA·A_F·V_RW²·cosθ（ISO 15016 形式）计入附加阻力**；**未含波浪增阻**（冰区通常被冰覆盖抑制，但敞水段应叠加 STAWAVE/ISO 波浪增阻），这是本版明确的局限。
8. **冰况为参数化情景**（Gaussian 冰脊 / 超高斯厚冰平台），不是实测/预报数据产品；接口已支持直接注入二维冰厚矩阵与多时效预报切片，但真实数据的接入与标定不在本节点范围。
9. 阻力模型沿用本仓 `api.ice.formulas` 的**校准版 Lindqvist**（其系数已按 ITTC 基准样本标定），本节点只做向量化复用与单点对账，未改其系数。
