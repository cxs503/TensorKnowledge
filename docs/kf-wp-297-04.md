## ① 本工序做了什么

单一工序：对上游工作包 `wp-297-01` 做独立审核（task_type `04-independent-review`，objective `judge_semantic_fidelity`）。审核面覆盖三件事：（a）上游结果信封与证据定位表的**逐字保真**（每条引用能否在源 markdown 原样切片、行号是否对齐）；（b）上游声明量（源哈希/字符数/资产数/状态）的**独立重算**；（c）源报告自身的**语义自洽性**（派生量互推、百分比重算、体积/网格闭合性）——因为这直接决定下游 02/03 能抽什么。

判决：`pass`，共 14 条 finding（severity：high 3 / medium 4 / low 4 / info 3）。其中 0 条判上游造假或引用不可复现；6 条标记 blocking，其对象全部是**源报告 297 的语义缺陷**（F-06, F-07, F-08, F-09, F-10, F-11），含义见 `blocking_scope`：blocking = must constrain downstream 02/03 extraction, NOT a failure of wp-297-01。

边界遵守：只读 `report_id=297` 与上游载体报告，未读未写其它 report_id；未改写上游产物；未把任何 claim 标成 verified（本信封不含 claims 字段，findings 只给 disposition 不给真值判决）。

## ② 怎么做的（步骤/工具/关键设置）

判据**先于**动手固定（写进脚本 `checks.json`，任一失败脚本返回非 0）：

1. `C1/C2` 源身份：重算 `sha256(markdown)` 与合同 `source_hash` 比对（无归一化 UTF-8），并把 markdown 逐字节落盘再哈希一次，提供第三方离线复算路径。
2. `C3/C4` 结构与 schema：用仓库内 `schemas/kf_result.v1.schema.json` 校验**上游**信封（内置最小校验器 + `jsonschema` 真校验器双判），并要求载体报告只含一个 json 块。
3. `C5` 证据保真：解析上游 ④ 表 6 行资产，逐条把 `quote` 在源 markdown 里 `find` + 反向切片比对（`md[start:end]==quote`），并把行号与上游声明行号对账。
4. `C6/C7` 算术审计：用正则从源 markdown 抽出主尺度、几何表、阻力表，**重算**报告自报的每个百分比，并对 `Rf`（由 Ct、Rt 反解湿表面积后复算）与 `Pe=Rt·V` 做闭合校验。
5. `C8` 几何合法性：由原文网格规模 (顶点数, 面片数) 计算欧拉示性数，检验『散度定理求体积』的前提（水密闭合三角流形须 chi=2）。
6. 独立物理重算：由 Δ 与 Cb 反推 ∇、用测得量表算体积项对比、把 B/T 换回官方值后重算 Cb，把 Cb 偏差拆成『梁宽偏大』与『体积偏小』两个独立分量；对 5600 kN 基准反推隐含 Ct/Cw 并与 Holtrop 计算的 Cw 比较。
7. 只读外部探测：对报告声称的计算端点做 GET（不 POST、不改状态），记录 `405 Method Not Allowed` ⇒ 路由存在、仅 POST，用于判断被引 API 面是否虚构。
8. 出图：matplotlib(Agg) 三联图（复算残差 / 排水体积完整性 / finding 严重度分布）。

上下文隔离：上游正文只被当作待检验断言，未采信其自述；判据来自工作包合同。工具链=Python3 标准库（urllib/json/hashlib/re/math）+ matplotlib；无外部模型调用。

一键复跑：`python3 artifacts/kf-wp-297-04/verify_review.py`（需 `TENSOR_API_BASE`/`TENSOR_AGENT_USER`/`TENSOR_AGENT_PASS`）。
