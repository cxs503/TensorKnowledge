## ① 案例介绍：这次要解决的"物理背景"是方法论战役的判据真空

`campaign_nodes`，见上图 a 面板）：A0–A6 七件基础机制全 `done`，试点 P1（TensorLBM 液滴入水）、

也就是说：机制层已落地，验证层的结论却多为「判据不可判」而非「算完了」——

- P1（m6334）：寄生流 max|u|=0.139（M≈0.24）使毛细压 `|Δp|` 最大 0.0047 低于声学不确定度 0.0092，
  Laplace 三半径自洽 R²=0.250、σ 变号 → 判据 **FAIL**，附加质量判据 **WITHHELD**；盲假设 H-A REFUTED。
- P2（m6335）：E 误差 3.50%、UCS 2.26 MPa 对文献中值 5.0 MPa 偏低 54.8%（**honest FAIL**）、
  ν 误差 8.4%、Weibull m **不可辨识**、巴西劈裂峰值随质量缩放 β 变化 988/329/165 N。
- A3（m6330）：局限 5 自认「run-manifest 未接回填器 → 回填产物落 candidate/E1」。
- G25 过门条件②「三试点至少 1 个实验组六维中 ≥2 维优于对照组」——P1 的六维点值在 SNR<1 下无意义、
  P2 单次实现无重复、P3 缺席，**当前不是不达标，而是不可判**。

## ⑤ 注意点（局限 / 适用范围 / 踩坑）

1. **本单是提案单，没有物理仿真**，图里没有场量云图——因为不存在被求解的场。所有量值均为
   对既有验收报告的**抽取**，不是新计算；这是图注必须写明的事，不做伪云图粉饰。
2. **关键词归类是启发式**：提案池 33 条标题里的「阻力的耐波修正」类条目会同时命中两个学科面，
   故图 1b 是「覆盖面提示」而非精确分类；0 格才有判定意义（三源同时 0 才敢称空白）。
3. **避免原地打转的边界**：P1/P2 的两条提案明确声明「不重跑异常表征/三腿流程」——它们清偿的是
   P1/P2 自己登记的失败判据（σ 可测、m 可辨识），交付物是**判据门与标定工具**，不是复述结论。
   A3 的提案严格锚在 m6330 局限 5 的原句「本节点未做」，不是重做 A3 的链检。
4. **统计功效提案不能自开 G25**：它只让条件②变成可裁，不判定过门；G25 仍须 owner 裁。
5. **扭振/砰击两条新面依赖平台既有耐波/推进模块**，若平台某模块缺 RAO 输出，G1/G3 判据会先
   fail-closed 而不是给近似结论。
6. **cluster 不可用**：本单曾尝试 `run_cluster` 拉取 TensorLBM 仓 `verified/` 清单做二次核验，
   节点回 `github.com:443 connect timeout`（无外网），故「仓内无 Laplace 案例」这一判断依据
   替换为：提案池 33 条 + 平台 `docs/` 清单 + P1 报告自述，属**间接证据**，仲裁者若需直接证据
   应在有网环境复跑该核验。
