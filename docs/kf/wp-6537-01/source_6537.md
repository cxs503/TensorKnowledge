# FuelEU Maritime 全生命周期碳强度合规引擎（IN39-N04）

> 模块：`backend/modules/fueleu`（领域目录新建）· 分支 `agent/m5552` · 判据与产物路径全部程序化写入 `artifacts/fueleu_in39n04/case_report.json`。

## 摘要

本节点建立一个可复算的 FuelEU Maritime 全生命周期碳强度引擎：12 条燃料路径的 Well-to-Tank / Tank-to-Wake / Well-to-Wake 强度（CH4 GWP100=29.8 / GWP20=82.1 双口径，N2O=273）、甲烷逃逸 0.1%–4% 敏感性、2025–2050 六级限值下的合规裕度与罚金（2400 EUR/t VLSFO-eq），以及多船联营（pooling）最优燃料组合的混合整数线性规划解。引擎把 TtW 完全建立在化学计量与含碳因子上（可独立复算），把 WtT 拆成开采/转化/输配/逸散/碳吸收五类显式分量，并用 IN23-N07（`modules.green_voyage`）的能耗链把航次剖面积分成年度能量。六道机器判据全部通过，其中加法闸残差 0.0e+00、与 IN23-N07 的年度 TtW CO2 相对偏差 4.9e-16、pooling 的 MILP 与暴力枚举（4096 组合）相对偏差 0.0e+00。

**证据分级声明（先于数字）**：TtW 与全部算术/单位/加和为 REAL（化学计量 + 定义式，任何人可用论文附录常数复算）；WtT 分量为**声明输入**（公开 LCA 量级，逐条带来源，不是拟合量）；法规默认值（附件 II WtT 锚、91.16 参考值、限值台阶、罚金单价）为**转录值**，`external_verification = WITHHELD`（离线环境无法访问 EUR-Lex 原文复核，见第 5 节）。

## 1 案例介绍：物理背景与算例

FuelEU Maritime 对船舶年度消耗能量的**能量加权平均温室气体强度**设限：

```
GHGI = Σ_j E_j·GI_j / Σ_j E_j   [gCO2e/MJ]，  GI_j = WtT_j + TtW_j
GHGI ≤ 91.16 × (1 − 减排率(year))
```

与 IMO 的 CII 不同，FuelEU 的强度是全生命周期的、且以 **MJ 能量为分母**（不是吨·海里），因此低热值燃料（甲醇 19.9、氨 18.6 MJ/kg）的"每吨排放"不能直接比较，必须换算到每 MJ。甲烷逃逸（LNG Otto 机未燃甲烷）在 GWP100 下把 LNG 路径推到与 VLSFO 相当甚至更差的水平，是整个规则体系中最具争议的一项。

## 2 怎么做：方法、流程与工具链

### 2.1 燃料路径模型（`fuel_path.py`）

```
TtW = CF·1000/LHV            （燃烧 CO2，REAL：化学计量 + 含碳因子）
    + slip·1000/LHV·GWP_CH4  （甲烷逃逸，slip 为燃料质量分数）
    + n2o·GWP_N2O            （燃烧 N2O，声明输入）
WtT = Σ_k c_k                （开采 / 液化 / 转化 / 输配 / 合成等分项）
    + m_fug·GWP_CH4          （上游逸散甲烷）
    − uptake·CF·1000/LHV     （生质/可再生碳吸收记负项）
```

每条路径带 `provenance`（逐项来源）与 `stoichiometric_cf()`（由分子式/含碳质量分数独立推出的 CF），后者构成**非循环**的化学计量闸。

### 2.2 能量链（`energy.py`，复用 IN23-N07）

航次剖面（距离 + 指令航速 + 燃料）逐段送入 IN23-N07 的 `simulate_voyage`（阻力 → 推进 → SFOC → 燃油率，含功率超包线时的显式降速），得到每航行时间与燃油质量；燃料切换按 `sfoc_scale`（能量等价比油耗倍率）缩放质量，能量 = 质量 × LHV。一个剖面只建一条能耗链（`reference_rows`），跨燃料复用，数值逐位一致。

### 2.3 合规与罚金（`compliance.py` + `regulation.py`）

```
ΔGI  = GI − GI_L ;  GHG_excess = E_tot·max(0, ΔGI)
tVLSFO_eq = GHG_excess / 3.73756e6  g   （91.16 gCO2e/MJ × 41.0 MJ/kg）
penalty   = 2400 EUR/t × tVLSFO_eq
```

### 2.4 联营优化（`pooling.py`）

每船一组离散燃料选项（GI + 单位能量价格，能量需求给定），以 "N 个 GUB 行 + 单一耦合行"的线性结构加 0-1 完整性，用 HiGHS MILP 精确求解；同时用无假设的离散枚举（本例 4096 种组合）做对账，并另算线性松弛（允许连续掺混）作为离散最优的下界。

### 2.5 工具链

- 计算：纯 Python + NumPy + SciPy（HiGHS MILP/LP）；无 GPU、无外部数据依赖。
- 测试：`pytest backend/modules/fueleu/tests`（64 个用例，覆盖六道判据 + API）。
- 接口：`/api/v1/fueleu/{fuels,regulation,gates,compliance,slip-sensitivity,pooling,voyage}`。
- 报告：`artifacts/fueleu_in39n04/run_case.py` 一键产出 JSON + 5 图；本文件由 `gen_report.py` 从同一 JSON 程序化生成（零手抄）。

## 5 注意点、局限与适用范围

1. **法规数值是转录值（WITHHELD）**：`regulation.py` 中的 91.16 参考值、六级减排台阶、2400 EUR/t 罚金单价与附件 II 的 12 条 WtT 锚，均按公开资料转录；本工作环境无外网，无法访问 EUR-Lex 原文做逐字核对。**因此判据①是内部一致性闸**（引擎的分项分解 vs 仓库内锚），不是外部合规验证。真正独立的物理验证由化学计量闸承担：由 CH4/CH3OH/NH3/H2 分子式与油品含碳质量分数独立推出的 CF，与法规 CF 的相对偏差 ≤0.25%。
2. **WtT 分项是声明输入而非推导**：开采/液化/转化/输配/逸散/碳吸收六类分量的取值落在公开 LCA 报告的量级区间内，但每一项都有区间（尤其生物/RFNBO 路径的碳源与电力碳强度）。引擎把它们显式暴露为参数（`_ELEC_CI`、`_ELEC_KWH_PER_KG_H2`、各 `wtt_fixed`），做敏感性时改参数即可复算，不做"隐藏常数"。
3. **TtW 的 N2O 是工程默认值**：船用发动机 N2O 实测离散度大（尤其氨燃料的 N2O 生成），本引擎按声明值（液体燃料 0.0006、氨 0.005 gN2O/MJ）计入；GWP 两口径取 N2O=273。
4. **联营模型把能量需求视为给定**：燃料切换只改 GI 与单位能量价格，不改能量需求。实际中换燃料会改变 SFOC（引擎用 `sfoc_scale` 表达这一阶效应并计入年度能量），但不会改变优化问题的线性结构。若把"换燃料 → 主机效率变化 → 能量需求变化"也内生，模型将变成非线性，不在本节点范围。
5. **线性松弛与离散最优的差**：允许连续掺混时的成本下界低于离散最优，本算例差额 19,480 EUR（0.17%）。判据⑥比对的是**离散最优 vs 离散枚举**，两者逐位一致；掺混下界只作为"如果允许混烧能再省多少"的信息列报。
6. **适用范围**：本引擎面向"给定燃料与航次 → 合规判定与联营优化"的评价问题，不含燃料全链条的过程模拟（如电解槽/重整炉的具体工艺），也不含 FuelEU 的banking（跨年结余）与 borrowing（借支）机制，以及乘数激励（RFNBO 乘数 2 倍、2033 年后到期）——这些是规则层的扩展项，结构上可在 `regulation.py` 增表实现。
7. **冰区/恶劣海况**：能耗链继承 IN23-N07 的环境修正；本算例用静水（`Environment()`），故年度能量是"平均海况代理"，与实船 AIS 统计会有偏差。

## 6 误差判定（逐项 vs 基准，显式回答是否 <3%）

| 关键量 | 基准 | 偏差 | 是否 <3% |
|---|---|---|---|
| WtT（12 条燃料） | 附件 II 转录锚 | 最大 0.260% | 是（≤1% 判据） |
| CF（化学计量 ⇒ TtW CO2） | 法规默认 CF（MEPC.364(79) 同族） | 最大 0.248% | 是 |
| 年度 TtW CO2 | IN23-N07 `simulate_voyage` | 4.9e-16（数值噪声级） | 是 |
| pooling 最优成本 | 离散暴力枚举（4096 组合） | 0.0e+00 | 是 |
| 甲烷逃逸斜率 | 解析 dWtW/dslip = 1000/LHV·GWP | <1e-12（差分 vs 解析） | 是 |
| VLSFO WtW vs 法规参考值 91.16 | 91.16 gCO2e/MJ（2020 船队平均） | 1.03% | 是 |

说明：最后一行是**弱基准**——91.16 是 2020 年船队平均强度（由实测油耗统计得到），并不等于 VLSFO 的燃料因子，二者相差 1% 属于口径差异而非误差；列在此处是为了给出量级一致性证据，不声称是精确复现。

**Honest 声明**：本节点没有可以"external verify"的法规原文核对（离线），因此判据①与法规数值层的事实正确性只能标 WITHHELD；已通过的一切闸都是**可复算的算术/物理一致性**与**内部对账**。若后续联网核对发现转录值与附件 II 原文不符，只需替换 `regulation.ANNEX_II_WTT` 的数值，全部判据与报告可一键复跑（`python artifacts/fueleu_in39n04/run_case.py && python artifacts/fueleu_in39n04/gen_report.py`）。
