
## 1. 案例介绍

### 物理背景
船舶阻力计算是船舶总体性能的核心学科。经典公式包括：
- **ITTC-1957 摩擦线**：Cf = 0.075 / (log10(Re) - 2)²，用于模型-实船换算
- **Blasius 层流解**：Cf = 1.328 / √Re_L，平板层流边界层精确解
- **Prandtl-Schlichting 湍流公式**：Cf = 0.455 / (log10(Re_L))^2.58
- **Holtrop-Mennen 形状因子**：1+k 的经验估算

### 参数表
| 公式 | 输入 | 输出 | 参考值来源 |
|------|------|------|-----------|
| ITTC-1957 | Re ∈ [1e6, 1e9] | Cf | 解析公式 |
| Blasius | Re_L ∈ [1e5, 1e6] | Cf | 解析公式 |
| P-S | Re_L ∈ [1e6, 1e9] | Cf | 经验公式 |
| Holtrop | Cb, L, B, T | 1+k | 简化经验公式 |

## 2. 方法

### AlphaEvolve 核心结构
1. **出题（Verifier 角色）**：从解析解/文献生成 held-out 题库，commit 冻结
2. **权限隔离**：题库 chmod 600，worker 不可读
3. **独立验证**：tp-ver-* 加载考卷，subprocess 运行候选，独立计算偏差
4. **Credit Ledger**：记录 verdict + evidence_hash，自测仅信息性

### 工具链
- Python 3.11 + SQLite（题库）
- subprocess（进程隔离）
- pytest（12 项单元测试）
- matplotlib（结果可视化）

## 5. 注意点

- 试点使用解析/经验公式，偏差为零是因为候选与出题使用相同公式。真实场景中候选可能有数值误差。
- 权限隔离依赖文件系统 chmod；生产环境应结合 Linux user namespace 或容器隔离。
- Holtrop-Mennen 形状因子使用了简化版本，完整版本需更多参数。
