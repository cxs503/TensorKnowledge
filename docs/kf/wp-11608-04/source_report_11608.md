## 1. 案例介绍

### 1.1 物理背景

数值黏性（numerical viscosity）和数值色散（numerical dispersion）是对流格式的核心特性，直接影响计算精度和稳定性。修正方程分析（modified equation analysis）是理解这些特性的理论工具，但需要数值实验验证。

本验证面针对一维线性对流方程：
```
∂u/∂t + c ∂u/∂x = 0,  周期域
```

初值为单波包：`u(x,0) = exp(ikx)`，通过测量振幅衰减和相位误差，反推数值黏性并与理论预测对比。

### 1.2 验证格式

覆盖四种经典对流格式：
- **一阶迎风（Upwind）**: 最稳定但最耗散
- **Lax–Wendroff**: 二阶精度， leading-order 无数值黏性
- **二阶中心（CD2）**: 纯色散，无数值黏性，但条件不稳定
- **QUICK**: 二阶迎风型，小但非零的数值黏性

### 1.3 参数空间

- **Courant 数**: C ∈ {0.2, 0.5, 0.8}
- **无量纲波数**: kΔx ∈ {2π×2/256, 2π×4/256, 2π×8/256} ≈ {0.049, 0.098, 0.196}
- **网格点数**: N = 256（确保波模式周期性）
- **总时间**: 2 个波动周期

## 2. 方法

### 2.1 数值黏性测量

对单波包 `u(x,0) = exp(ikx)` 进行时间推进，提取 t 时刻的振幅 A(t)：

```
ν_num^meas = -ln(A(t)/A(0)) / (k² t)
```

### 2.2 理论预测

**修正方程 leading-order 数值黏性**：
- Upwind: `ν_th = cΔx(1-C)/2`
- Lax–Wendroff: `ν_th = 0`（leading order）
- CD2: `ν_th = 0`（纯色散）
- QUICK: `ν_th = cΔx(1-C)(1-C²)/8`

**精确 von Neumann 放大因子**：
```
G(θ) = u^{n+1}/u^n  (对模式 exp(ijθ))
ν_exact = -ln|G| / (k² Δt)
```

### 2.3 验证流程

1. **单波包实验**: 对每种格式、每组 (C, kΔx)，运行时间推进，测量 A(t)/A(0)
2. **反推 ν_num**: 从振幅衰减计算 ν_num^meas
3. **对比理论**: 与 ν_th（修正方程）和 ν_exact（von Neumann）对比
4. **von Neumann 全域扫描**: θ ∈ (0, π)，49 个点，验证 |G_num - G_ana| < 1e-3
5. **网格收敛**: Δx 减半，验证 ν_num 减半（对耗散格式）
6. **二维对角对流**: 检查交叉导数项 ν_xy

### 2.4 工具链

- **求解器**: 自研 1D/2D 周期域对流求解器（numpy）
- **时间推进**: 显式 Euler
- **模式提取**: 内积法（与精确模式 exp(ikx) 做内积）
- **可视化**: matplotlib

## 5. 注意点

### 5.1 波模式周期性

**问题**: kΔx = 0.05, 0.1, 0.2 不是 2π 的有理倍数，无法在有限网格上严格周期。

**解决**: 使用兼容波数 kΔx = 2π×m/N（m=2,4,8; N=256），近似为 0.049, 0.098, 0.196。

**影响**: 物理结论不变，仅数值略有差异（< 0.1%）。

### 5.2 Lax–Wendroff 的高阶耗散

**发现**: L-W 的 leading-order 数值黏性为 0，但高阶项贡献 ν ~ O(Δx³)。

**实测**: ν_LW ~ 1e-4 ~ 1e-3，比 upwind（ν ~ 0.1 ~ 0.4）小 2-3 个量级。

**意义**: 验证了 L-W 的二阶精度特性。

### 5.3 QUICK 格式的稳定性

**发现**: QUICK 在某些参数下（大 kΔx、大 C）可能不稳定。

**本验证**: 使用小 kΔx（≤ 0.2）和中等 C（≤ 0.8），QUICK 稳定。

**建议**: 实际应用中需限制 C ≤ 0.5 或使用隐式时间推进。

### 5.4 二维交叉导数项

**发现**: 2D 对角对流时，upwind 的数值黏性包含交叉项 ν_xy。

**实测**: 2D upwind 的振幅衰减略大于 1D 预测（约 5%-10%）。

**解释**: 交叉导数项贡献额外耗散，符合修正方程分析。
