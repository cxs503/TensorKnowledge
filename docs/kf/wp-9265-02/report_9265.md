## ① 案例介绍（物理背景 / 几何 / 参数表）

本节点评估一艘典型 **DP-2 海工供应船（PSV, UT-755 级）** 的 DP 能力：3-DOF 静力平衡能力包线与
单推力器失效后的能力降级。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

四层结构，全部在 `dp_core.py`，端点只做编排与出图。

**L1 推进器模型（REAL,** 推导而非拟合）
螺旋桨定律 `T = ρD⁴K_Tn²`、`P = 2πρD⁵K_Qn³` ⇒ 消去转速得 **`T ∝ P^{2/3}`（指数 2/3 是精确解析结果，测试用 8 倍功率验证到 1e-12）**。
由此 `P(T) = P_max(|T|/T_max)^{3/2}`，`T_max` 由装机功率反算（K_T=0.50、K_Q=0.055 为涵道值）。
执行器运动学：全回转（2 变量 + 圆饱和）、侧推/固定向（1 变量 + 盒饱和）、方位角速率限
（2.5~3.0 °/s）、推力速率限（20~40 kN/s）。

**L2 环境力模型**
- 风：上层建筑分块（船体干舷 / 货甲板 / 居室 / 烟囱 / 首楼）的**平板法向力积分**
  `F_n = q·κ·C_d(AR)·A·sin²(入射角)`，C_d(AR) 按经典平板数据随展弦比 1.18→1.30 插值，
  κ 为圆化/钝体修正（干舷 0.65、上层建筑 0.85）。⇒ `C_X(0)=−0.72`、`C_Y(90°)=−1.33`、`C_M(90°)=−0.165`。
- 流：纵向用 ITTC-57 摩擦线 `C_F=0.075/(log₁₀Re−2)²` + 形状因子 (1+k)=1.15 作用于湿表面积；
  横向用**沿船长分布（吃水型线加权）的横流阻力** `C_d=1.0`，因此自然给出艏摇力矩。
  ⇒ 1 m/s 横流 235.3 kN；1 m/s 纵向流 2.45 kN。
- 波浪平均漂移力：**远场二维条带模型**，单位水线长 `F' = ½ρg a²|R|²`（完全反射 |R|=1 时即经典
  直立壁结果 ½ρg a²），反射系数取阻塞能量论证 `|R|²=(1−e^{−2kT})²`（长波/大吃水→全反射，
  短波→从船底通过）。海况 JONSWAP（γ=3.3，∫S dω = Hs²/16 归一化）。
  ⇒ Hs=2 m/Tp=8 s 横浪 76.4 kN，Hs=4 m 精确 4 倍（305 kN）。

**L3 推力分配 QP（REAL）**
以**无量纲利用率** `e_i = u_i/T_max,i` 为变量：
```
min_e  Σ (w_i (e_i − r_i)²)        (二次型, 良态)
s.t.   (A D) e = τ                 3-DOF 静力平衡
       |e_i| ≤ 1                   盒饱和（侧推/固定向）
       hypot(e_i,e_j) ≤ 1          圆饱和（全回转）
```
等式约束**解析消去**：`e = e_p + N z`，`e_p = A_e^T(A_eA_e^T)^{-1}τ`（最小能量解析解），
`N = null(A_e)`，于是平衡残差天然为机器精度，SLSQP 只需处理执行器限幅不等式；
若 `e_p` 已满足全部限幅则**不调用求解器**（`iterations = 0`）。
三种模式：`min_power`（最小二次能量，标准 DP 代理目标）、`min_wear`（抑制推力变化/磨损）、
`min_kw`（真正的最小轴功率 `ΣP_max|e|^{3/2}`，用于量化代理目标差距）。失效容错 = 变量移除。

**L4 操作包线**
对每个环境来向（0~330°，步长 30°）× 电流速度（0, 0.5, 1.0, 1.5, 2.0 m/s），
风/浪/流共线同向，海况固定 (Hs, Tp)，**对风速二分**（容差 5e-3 m/s）求可行上界；
可行性由独立凸 QP `min‖A_e e − τ‖² s.t. 限幅` 判定（凸性问题 ⇒ 零残差即可行性的充分必要条件）。
容差内可行点再跑一次完整分配 QP 记录利用率与功率。
失效分析：逐个移除推力器重算包线，输出最坏艏向 / 平均 / 能量加权三种降级度量。

**工具链**：Python 3.11 / numpy 2.4.6 / scipy 1.16.0（SLSQP、bvls）/ matplotlib 3.10.8 / FastAPI 0.136.1 + TestClient。
算例运行 90.9 s（含 4 档海况的失效敏感性）。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **风载荷面朝向坑**：分块几何里 `w`(纵向)×`h` 是横向投影面（迎头风看到的面），`b×h` 才是侧面；
   初版写反导致 `C_X(0)=−1.73`（应为 −0.72）。测试 `test_wind_head_and_beam_coefficient_bands`
   钉住量级带。
2. **JONSWAP 归一化坑**：Hs/Tp 参数化必须用 `ω_p⁴ω^{−5}`（若误写 `T_p^{−4}ω^{−5}` 谱面积小 3 个量级，
   漂移力被算成 0）。测试用 `∫S dω = Hs²/16` 钉死（实测偏差 0.4%，来自网格截断）。
3. **QP 量纲坑**：以 kN 为单位、权重 1/T² 时目标函数量级 ~1e-4，SLSQP 的 `ftol` 立即判定收敛
   ⇒ 优化器在起点就退出（表中一度出现"磨损模式完全无效"）。改为无量纲利用率空间后消失。
4. **可行性判定要用凸问题**：先做盒松弛（bvls）得到残差下界，再用独立凸 QP 判可行，
   避免在显然不可行的点上把 SLSQP 迭代预算耗尽（改进前包线扫描出现过 `nit = 50`）。
5. **局限（适用范围必须写明）**
   - 静力 3-DOF：无低频/波频动态、无控制器、无瞬态与推力器再分配过程（只用速率限做静态可行性）。
   - 风/流/波浪漂移系数的**绝对值**属工程级模型（分块积分 / ITTC-57+横流 / 远场条带 + 阻塞反射），
     仓库内没有风洞、模型试验或 OCIMF/Isherwood 回归表可对标 ⇒ **数值层 WITHHELD**，
     只声明结构正确性（渐近、对称、V²/Hs² 标度）与量级带。
   - 波浪漂移在艏斜浪按"各向同性条带量级 + 方向投影"处理，未含实船艏斜浪的反射减弱。
   - 结果对海况高度敏感（见 3.3）：同一船型在 Hs 2 与 Hs 3 下 DP-2 冗余结论相反，报告包线时必须
     同时声明 Hs/Tp/电流。
   - `backend/main.py` 在本容器内**整体 import 失败**（缺 `openpyxl`，与本次改动无关），
     因此端点验证用同前缀挂载的 FastAPI 子应用 + 对 `main.py` 注册行的静态检查（测试
     `test_router_registered_in_main_with_expected_prefix`）。

## ⑥ 误差判定（逐项，显式回答"是否 <3%"）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| `T ∝ P^{2/3}` 指数 | 螺旋桨定律解析解 | 1e-12（相对） | **是** |
| `T(P)` 往返闭合 | 解析 | 1e-12 | **是** |
| ITTC-57 `C_F(Re=1e9)` | 0.075/49 = 1.5306e-3 | 0（同一闭式） | **是** |
| Holtrop 湿表面积（箱型极限） | L(2T+B) | <5%（箱型理想化），实船偏差未对标 | 部分（结构） |
| JONSWAP 谱面积 | Hs²/16 | 0.4% | **是** |
| 波浪漂移完全反射极限（单位水线长） | ½ρg·Hs²/16 → ρgHs²/16 | 0.2%（网格） | **是** |
| 波浪漂移 Hs² 标度 | 解析 | 4e-16 | **是** |
| QP 解 vs KKT 闭式解 | 解析 | 7.1e-15 kN | **是** |
| 3-DOF 平衡残差（10 点） | |F_env−F_thrust|/|F_env| | 0（≤1e-15） | **是** |
| 二次代理 vs 真正最小功率 | 最小功率 QP | 2.77~2.81% | **是** |
| 风/流/波浪漂移系数绝对值 | 模型试验 / Isherwood·OCIMF 回归表 | **无基准** | **无基准，声明 WITHHELD**（仅核量级带 C_X 0.6~1.2、C_Y 0.8~1.5） |
| 包线风速绝对值 vs DNV 已发表 PSV 图 | 公开图 | **无基准** | **无基准，声明 WITHHELD**；仅做定性特征对照（5/5 通过） |
| 单件失效降级 ≤30% | 战役判据 | Hs≤2.5 m: 22.98~28.00% **PASS**；Hs=3 m: 36.30% **FAIL** | **部分**（如实记录，未粉饰） |

对"降级 ≤30%"的诚实结论：在 1 kn 共线流 + Hs ≤ 2.5 m 的设计海况下最坏艏向降级 22.98~28.00%（通过），
平均降级 9.1~14.4%；**Hs = 3 m 时最坏艏向 36.30%，超过判据 30%**——原因是此时横向裕度仅约
1.4 倍（横流 529 kN + 漂移 172 kN 对应 ~540 kN 可用横向能力），失掉一个尾部全回转推力器
即损失 ~30% 横向能力。这是物理结论而非数值误差，故原样报告：该船型 DP-2 冗余在 Hs ≳ 2.5 m 时不足，
改进方向（加装第二台首部全回转 / 增大侧推 / 提高可用推力系数）留给后续节点。
