# 料仓卸料(Beverloo)+休止角双案例 —— TensorDEM 跨方法吸收线

## 1. 案例介绍
三维软球 DEM（线性弹簧-阻尼 + 带历史 Coulomb 摩擦、cell-list Verlet 邻居表、速度 Verlet）复现两类经典颗粒基准：
①平底圆筒料仓（D/d=22.5）经圆孔出流的稳态质量流率，检验 Beverloo(1961) 定律 ṁ = C ρ_b √g (B−kd)^{5/2}；
②单分散球堆休止角（AOR）并与玻璃珠文献区间 20–25° 对照。
材料：d=4.00 mm 玻璃珠，ρ_p=2500 kg/m³，k_n=1.0 kN/m，e=0.60，μ=0.25，Δt=50 µs（≈13 步/接触），N=7637。

## 2. 怎么做的
①密排格点装料→②关孔重力密实 0.12 s，测堆积密度与孔隙率→③开孔，记录每颗粒穿越孔口平面的时刻→④取流量时间序列平台段求稳态 ṁ→⑤对 (B−kd)^{5/2} 线性回归。
AOR：柱状松堆塌落 + 点源注入两种方案，按 1 倍粒径环带取自由面最高点做直线拟合。
链：`src/tensordem/granular_dem.py` → `examples/hopper_beverloo_case.py` → `hopper_beverloo_report.py`（数字全部由程序从 outputs/*.json 注入 CASE.md，零手工抄写）。

## 5. 注意点 / 局限
软球 k_n=1 kN/m（实测最大重叠 1.5% d）；格点装料记忆使孔隙率 0.605 略高于随机堆积；
B/D 达 0.40（超出 Beverloo 严格适用区的上界）；孔口为尖锐平面、球心判据，未做倒角；
可用孔径窗口被成拱限制在 B/d=8–9，x 跨度仅 43%，截距与斜率强相关；
休止角失败根因：无转动自由度 → 缺滚动摩阻，缓注时按注入格点对位堆塔、高柱塌落时摊成薄饼（R²≈0.33），自由面已非直线。

## 6. 误差判定
- 求解器自验证：自由落体最大位置偏差 0.00e+00 m；恢复系数 0.616 vs 0.60（+0.00%）；Coulomb 滑动减速 0.000 vs μg=0.000 m/s²（+0.0e+00%）；邻居表 vs 暴力枚举 0/0 对，0 不一致。以上四项均 <3%（除库仑项为机器精度）。
- 硬门①：R²=0.99498 ≥ 0.99 **通过**；C∈[0.55,0.65] **未通过**（0.766 自由截距；过原点 0.646 在区间内但 R²<0）。逐点 <3% 判据：上述相对偏差中最大为 +5.82%（B=32 mm），其余两点 <2%，**未全部 <3%**。
- 硬门②：休止角**无有效测量**（honest FAIL），原因如上，不得含糊。
