## 1. 案例介绍

**物理背景**：冰板浮于水面，受集中载荷作用。水面对冰板的支撑可建模为 Winkler 弹性地基（压力与挠度成正比：q = k·w）。

## 2. 方法

**数值方法**：TensorFEM Q4 Mindlin-Reissner 板单元（选择性减缩积分 SRI）+ Winkler 地基刚度耦合。

**关键设置**：
- 板尺寸：10l × 10l（≈ 101m × 101m），确保边界效应可忽略
- 网格：16×16 单元（256 单元，289 节点）
- 边界条件：简支（simply supported）
- 集中力施加于中心最近节点
- 求解器：直接法（torch.linalg.solve）

**验证策略**：
1. 中心挠度 vs Hetényi 解析解
2. 网格收敛性（h-refinement）
3. 挠度场径向分布 vs Kelvin kei 函数
4. 缩放律验证（w ∝ P，w ∝ 1/√k_f）

## 5. 注意点

1. **板尺寸选择**：有限板必须足够大（≥ 8l）才能近似无限板。8l 板在 nx=12 时误差 2.3%，满足 <5% 验收线。
2. **中心节点选取**：必须取距板中心最近的节点，而非掩码中的第一个节点。
3. **Mindlin 板理论**：本实现使用 Mindlin-Reissner 理论（含横向剪切变形），而 Hetényi 解基于 Kirchhoff 薄板理论。对于 t/l = 0.5/10.13 ≈ 0.05 的薄板，剪切效应可忽略。
4. **Kelvin 函数**：Hetényi 解使用 Kelvin kei 函数，在 r ≈ 3.8l 处出现抬升环（挠度变号），FEM 解也捕捉到了这一物理现象。
