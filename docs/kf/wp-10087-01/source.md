
# P97-N02: DEM单颗粒压碎验证面——Weibull强度-尺寸效应 + 子粒替换守恒账本 + Gaudin破碎谱

## ① 案例介绍

### 物理背景
单颗粒压碎是离散元（DEM）破碎模型的基础验证面。当颗粒在两个刚性平板间受压时，接触力产生名义应力 σ = F/(πr²)；颗粒的破坏服从Weibull统计强度理论：

$$\sigma_f(V) = \sigma_0 \left(\frac{V}{V_0}\right)^{-1/m}$$

$$P_f(\sigma, V) = 1 - \exp\left[-\left(\frac{\sigma}{\sigma_0}\right)^m \frac{V}{V_0}\right]$$

其中 m 为Weibull模量（控制强度分散性），σ₀ 为特征强度，V₀ 为参考体积。

破碎后母粒被 N 个子粒替代，须满足：
- **质量守恒**：Σm_i = m_parent
- **动量守恒**：Σm_i v_i = m_parent v_parent + Δp_fracture

子粒粒径服从Gaudin-Schuhmann分布：F(d) = (d/d_max)^α

### 参数表

| 参数 | 石英砂 | 石灰岩 |

## ② 方法

### 加载模拟
- 单球体在两个刚性平板间准静态加载
- Hertz接触：F_c = (4/3)E*√r · δ^(3/2)，E* = E/(2(1-ν²))
- 对称加载总力 F = 2F_c，名义应力 σ = F/(πr²)
- 时间步长 dt = 1μs，最大加载时间 t_max = 200ms

### Weibull采样
- 每次试验一次均匀随机数 U ~ Uniform(0,1)
- 颗粒在 P_f(σ(t)) ≥ U 的首个时间步破坏（单调加载路径的精确逆CDF采样）
- 每个粒径做300次试验取中位数

### 子粒替换
- 从Gaudin谱逆CDF采样 N 个子粒直径
- 均匀缩放使 Σr_i³ = r_parent³（质量守恒精确到浮点精度）
- 子粒速度 = 母粒速度 + 质量加权零均值随机散布（动量守恒精确到浮点精度）

### Gaudin谱拟合
- MLE估计：α̂ = n / Σln(d_max/d_i)
- CDF对数线性拟合：ln F = α ln d - α ln d_max

## ⑤ 注意点与局限

1. **制造解验证**：本节点的"实验数据"是从解析Weibull律和解析Gaudin谱生成的制造解，验证的是管线（模拟+采样+守恒+拟合）的正确性，而非真实石英/石灰岩的材料参数。
2. **准静态假设**：忽略了颗粒惯性，适用于单颗粒压碎的标准测试条件；高速冲击需引入动态效应。
3. **球形假设**：颗粒为完美球体，实际岩石颗粒形状不规则会影响应力分布和破碎模式。
4. **Gaudin谱的局限**：Gaudin-Schuhmann是经验谱，实际破碎谱可能更复杂（如双峰分布）；本节点验证的是谱的数学一致性而非物理真实性。
5. **管线MLE偏差**：当多事件混合不同d_max时，MLE估计会偏低（0.78 vs 1.5），CDF拟合更鲁棒。
