## 1 案例介绍

### 1.1 为什么做这件事

EEXI/CII 是"达到值 ≤ 要求值"的**二元合规判定**。达到值由几何、阻力、推进、主机四段物理链
逐级推出，每一段都带公差/散布；要求值由规则系数（离线转录，`WITHHELD`）与载重量决定。
把达到值当成确定数得到的"合规/不合规"其实是一个概率事件的点估计——**在边界附近的船上，
这个点估计毫无信息量**。本节点给出该判定的完整概率描述：

* `EEXI_attained` / `CII_attained` 的概率密度、分位数、均值/标准差；
* 合规概率 `P(EEXI ≤ EEXI_req)`、`P(CII ≤ CII_req)`、`P(两者同时合规)`；
* 方差按**六因子**（几何/阻力/推进/主机/气象/操作）的 Sobol 分解——回答"该先去压哪个公差"。

### 1.2 设计案例（Kamsarmax 散货船，80 000 dwt）

| 项目 | 取值 | 说明 |
|---|---|---|
| `Lpp × B × T` | 229.0 × 32.26 × 14.45 m | 巴拿马型上限，散货船典型主尺度 |
| `Cb / Cm / Cp` | 0.842 / 0.995 / 0.846 | `Cp = Cb/Cm`，落在 Holtrop 回归域内（`Cp ≤ 0.85`） |
| 排水量 | 92 130 t（∇ = 89 883 m³） | `∇ = Cb·L·B·T`（几何自洽闸门，偏差 0.19%） |
| DWT（capacity） | 80 000 t | 空船重量比 0.13 ⇒ 反算 DWT 80 154 t |
| 主机 | MCR 11 000 kW、SFOC 175 g/kWh、HFO（`C_F = 3.1108`） | 燃油碳因子由化学计量导出（本体 `REAL` 层） |
| 限功率 | EEXI 参考点可用功率 = 0.57·MCR = 6 270 kW | 等价于 EPL 至 76% MCR，参考点取限功率后 75% |
| 推进 | `η_D = 0.72`、`η_S = 0.99` | 总推进效率与轴系效率 |
| 营运 | 服务航速 12.0 kn（减速航行）、CII 年份 2026 | CII 2026 Z = 0.11 |

设计点**刻意取在合规边界附近**（`EEXI/req = 1.006`、`CII/req = 0.985`），使合规概率成为有
信息量的量（≈0.4–0.6），而不是退化的 0/1。要求值：`EEXI_req = 3.5269`、`CII_req = 3.7662`
gCO₂/(t·nm)（`WITHHELD`：系数转录自 MEPC.328(76)/MEPC.353(78)，离线不可回读原文）。

## 2 怎么做的

### 2.1 确定性链（被传播对象）

```
几何 m_L,m_B,m_T,m_Cb → L,B,T,Cb；Cp = Cb/Cm，Cwp = (1+2Cb)/3，∇ = Cb·L·B·T
            │
            ├─ R_T(V) = Holtrop-Mennen 唯一实现（backend/physics/holtrop）   [kN]
            │      乘阻力模型因子  R_T,tot = k_R · R_T
            ├─ P_B(V) = k_R·R_T(V)·V /(η_D·η_S)                       [kW]
            │      乘气象余量      P_req(V) = f_aw · P_B(V)
            │
            ├─ EEXI 参考点：P_avail = 0.57·MCR·k_EPL，V_ref 由功率平衡反解
            │      P_req(V_ref) = P_avail  ⇒  V_ref（对数空间牛顿迭代，1/3 幂律指数）
            │      EEXI_attained = (P_avail·SFOC·C_F + P_AE·SFOC·C_F)/(f_i f_c DWT·V_ref)
            │
            └─ CII 营运点：V_s = 12.0·k_Vs
                   P_s = f_aw·k_R·R_T(V_s)·V_s/(η_D η_S)
                   CO₂/h = (P_s + P_AE)·SFOC·C_F·(1+φ)
                   CII_attained = CO₂/h /(DWT·V_s)
```

三条纪律：

1. **规则公式零重写**：`EEXI_attained`/`CII_attained` 一律调用
   `api/green_shipping` 的 `_gn_attained_index` / `_gn_attained_cii` / `_PowerChain`，
   要求值调用 `_gn_required_eexi` / `_gn_required_cii`。本模块只提供**上游物理**与**统计学**。
   判据 C1 证明同输入下相对差 < 1e-9。
2. **几何必须自洽**：`Cb·L·B·T` 与 DWT 闭合（偏差 ≤2%），`Cm` 固定、`Cp = Cb/Cm`、
   `Cwp = (1+2Cb)/3`，Cb 变化时水线面同步变化（否则等于凭空造船）。
3. **参考航速是解出来的，不是给的**：V_ref 由 `P_req(V)=P_avail` 反解——这正是"阻力与推进
   不确定度进入 EEXI"的物理通道。迭代式 `V ← V·(P_avail/P_req(V))^{1/3}`，3–4 次阻力
   评价收敛（对照 `brentq` 需 23 次）。

### 2.2 统计工具链

| 环节 | 实现 | 关键设置 |
|---|---|---|
| 抽样 | 标准正态空间 i.i.d. / 拉丁超立方（LHS） | MC 用 LHS（方差缩减），Sobol 用 i.i.d.（A/B 独立） |
| 主 MC | `green_uq.mc.run_mc` | N = 200 000，LHS，批均值法标准误（16 块） |
| Sobol | `green_uq.sobol`：Saltelli 设计 + **Jansen** 估计量 | N = 32 768 基样本 ⇒ 21·N = 688 128 次链评价；变量级 13 + 组级 6 |
| 解析锚点 1 | δ 法（一阶二阶矩）：`c_i = ∂ln y/∂z_i` 由**链条方程**解析推出 | `Var(ln y)=Σc_i²`，`S_i = c_i²/Σc_j²` |
| 解析锚点 2 | 对数正态线性链**精确闭式** `y=y₀exp(Σc z − ½Σc²)` | `S_i=(e^{c_i²}−1)/(e^{Σc²}−1)`，均值严格 = y₀ |
| 解析锚点 3 | 真实链中心差分灵敏度互证（h = 2σ） | 避开 Holtrop 报告值 0.01 kN 的量化地板 |
| 负控 | σ 全谱缩放到 ε = 1, 0.1, 0.01, 1e-3 | 标准差应线性缩小，合规概率退化为阶跃 |
| 收敛 | N = 1e4/3e4/1e5/3e5 | 判据：末两级 std 漂移 < 2%、概率漂移 < 0.01 |

**为什么 Sobol 用 Jansen 而不是 Saltelli-2010 相关式**：相关式一阶估计量方差过大（本节点实测
在二维主导玩具模型上 N=16384 时标准误达 0.05，出现 S_i > 1 的伪值）。Jansen 的平方差式与
全效应用同一批模型评价，标准误小一个量级，且同样满足 `S_i ≥ 0`。

### 2.3 顺带修掉的缺陷（本节点副产物，非目标但影响全部 EEXI/EEDI 结论）

`api/green_shipping._gn_attained_index` 的分母原为
`f_i f_c f_l · capacity · V_ref[m/s] · 3600`（= `capacity·V_ref[kn]·1852`），
使 **EEXI/EEDI 达到值系统性偏小 1852 倍**，任何船的"合规"判定都恒为 `True`
（对设计案例：原值 0.00221 vs 正确值 4.09 gCO₂/(t·nm)）。
本节点改为 `capacity·V_ref[kn]`（= 每小时吨海里），并新增量纲回归测试
（`test_chain.py::test_attained_index_unit_1852_fix`，相对差 < 1e-12，旧/新比值 = 1852 ± 1e-9）。
影响面：`/api/v1/green-shipping/{eedi,eexi}` 的 `attained_value`/`ratio`/`compliant` 三处；
原有 18 条 `test_green_shipping.py` 断言（只断言 `idx > 0`）全部仍通过。

**物理解读（这才是节点要回答的问题）**

* **EEXI 的方差由"主机"主导**（0.416）：MCR 公差 3%、SFOC 公差 2% 各贡献
  0.203/0.209。原因清楚——EEXI 的定义式里
  `P_avail·SFOC` 直接出现在分子，指数为 1（SFOC）与 n/(n+1)=0.67（MCR），是链上最短路径。
* **阻力模型形式误差是第二大项**（0.204，指数 1/(n+1)=0.33）：
  Holtrop ±6% 的回归散度经 V_ref 反解被"打折"到 0.33 次方，这解释了为什么"提升阻力预报精度"的
  边际收益小于"产品台架试验把 SFOC 公差压死"。
* **几何公差几乎无关**（0.036，其中 Cb 一项 0.031）：
  主尺度 ±0.5–2% 经 R_T 的弱幂律（∂ln R_T/∂ln Cb ≈ 0.02）传递到指数后只剩千分之几。
  工程含义：**不必为 EEXI 去抠船体丈量公差，应去抠主机台架与试航修正**。
* **CII 的方差结构完全不同**：阻力 0.362、气象
  0.245、操作 0.191
  （其中航速一项 0.161，CII∝V²）、推进 0.089，
  主机反而只有 0.039（CII 用营运功率，不进 75%MCR 参考点）。
  这解释了行业实践：**对 CII 最有效的杠杆是减速与气象航线（V_s、f_aw），对 EEXI 是主机/限功率**。

## 4 注意点（踩过的坑 / 局限）

1. **Holtrop 返回的是"报告值"**：`Holtrop1984Output.RT` 四舍五入到 0.01 kN（在 628 kN 上
   相对量化 ≈ 8e-6）。用 h = 1e-3 做有限差分时，几何灵敏度被量化噪声淹没，甚至会**翻错符号**
   （实测 `∂ln R_T/∂z_T` 得到 −0.008，真值 +0.0088）。纪律：差分步长取 2σ（h = 0.02），
   并把求 V_ref 的迭代残差从 5e-5 临时收紧到 1e-8。
2. **求速迭代的收敛判据被量化地板"卡住"**：残差在 1e-6…1.5e-5 之间跳动，若判据设 1e-9 会
   永远"不收敛"（并把每次评价成本放大 5 倍）。正确做法是把判据设在量化地板之上（5e-5），
   并在文档中写明这一上限（对应 V_ref 相对精度 1.7e-5、EEXI 精度 <2e-5）。
3. **小一阶 Sobol 指数量不出来**：一阶指数 ~1e-3 量级（几何组）在 N=32768 下的标准误约
   0.01，属"分辨率以下"。因此判据 C4 的容差写成 `max(0.03, 3·SE)` 而不是硬编码 0.03，
   并在 `results.json` 里逐项输出 SE——不偷偷放宽，也不假装能分辨。
4. **要求值也带不确定度**：capacity（DWT）同时进入达到值分母与要求值参考线，两者**相关**。
   本节点把合规概率按"逐样本耦合"计算（`P(EEXI_attained(y) ≤ EEXI_req(y))`），并另给
   "要求值钉在名义 DWT"的对照，避免把相关性当噪声。
5. **Holtrop 回归域边界**：Cb 的 1.5% 散布使部分样本 `Cp` 略微越过 0.85 上界（比例见
   `monte_carlo.numerics.out_of_holtrop_domain`）。这是**边界外推**而非失效：`Cp` 只经
   c2/c5/c15/c16 等系数进入，函数在该点连续，对 σ 的影响为二阶；但报告如实给出比例，
   不隐藏（honest 计数，不做样本剔除）。
6. **推进效率未与桨系列闭合**：η_D 按题设作为独立乘子输入，未用 B 系列桨 J/K_T/K_Q 与阻力
   建立相关性。若后续把 η_D 与 R_T 通过自航因子 `t, w` 耦合，推进/阻力两组的 Sobol 份额会
   重新分配（预计阻力份额略降、交互项上升）。
7. **φ（港内 CO₂ 占比）不是乘性因子**：它通过 `ln(1+φ)` 进入，解析灵敏度用
   `∂ln(1+φ)/∂z = s_ln·φ̄/(1+φ̄)`（不是 `cv`）。解析式与有限差分吻合到 4%，但它是本谱里
   唯一"非乘性"因子，换成大 φ 时必须重推，不能沿用乘性闭式。
8. **规则系数离线转录（`WITHHELD`）**：合规概率只反映达到值 + 载重量的不确定度，不含
   规则系数本身的不确定度；结论不得单独作为规范符合性证明。
9. **EPL 单参数化**：限功率以 `epl_fraction` 单参数表示（0.57 = 76% MCR 后再取 75%），
   未建模调速器动态与 ShaPoLi 的功率-转速映射细节。
10. **参考航速路径**：V_ref 由功率平衡反解，等价于"模型试验/试航反推"，未含试验测量误差
    （已用 `k_R`、`k_ηD` 因子近似覆盖其量级）。
