# DEM多面体颗粒与冰-结构混合模式失效验证面

## 1. 案例介绍

### 物理背景
本节点实现两类关键能力：
1. **多面体颗粒DEM**：非球形颗粒（冰碎块、岩石）的接触检测与力计算
2. **冰-结构混合模式失效**：压溃/弯曲/劈裂三种失效模式及转变条件

### 几何与参数
- 多面体颗粒：正二十面体（12顶点），半径0.01m，密度1000 kg/m³
- 冰参数：σ_c=3 MPa, σ_f=0.7 MPa, σ_t=0.7 MPa, h=1.0 m, E=5 GPa
- 结构宽度：D=10 m（默认）

## 2. 方法

### 多面体接触检测
- GJK/EPA算法（已有convex_contact模块）
- 法向力：线性弹簧-阻尼器 F_n = k_n·δ - γ_n·v_n
- 切向力：Cundall-Strack增量弹簧 F_t = -k_t·Δu_t
- 滚动阻力：EPSD模型 T_r = -μ_r·r_eff·|F_n|·ω_r/|ω_r|

### 冰失效模式
- 压溃：R_crush = 2.5·σ_c·h·D·f(V), f(V)=min(1+0.3V, 1.5)
- 弯曲：R_bend = 0.7·σ_f·h²·L_b·(1+0.1V), L_b=(Eh³/(12(1-ν²)ρ_wg))^(1/4)
- 劈裂：R_split = 1.5·σ_t·h·D·g(D/L_b)
- 临界速度：V_c = 0.1·√(σ_f/(ρ·h)) (Timco 2001)

## 5. 注意点

### 局限
1. 简化DEM显式时间积分；精确量化预测需更高级积分器
2. 准静态冰阻力公式；未捕获动态效应和应变率效应
3. 临界速度公式为经验公式；实际转变依赖多因素
4. 力链各向异性度量简化（力幅值方差）

### 适用范围
- 多面体颗粒：凸多面体，GJK/EPA接触检测
- 冰失效：工程近似公式，适用于初步设计
- 模式转变：V_c公式适用于水平冰-垂直结构

## 6. 误差判定

| 关键量 | 基准 | 误差 | 是否<3% |
|--------|------|------|---------|
| 休止角 | 实验30-45° | 0-70° | 否（简化模型） |

| R_total | Lindqvist 1.1 MN | 63% | 否（不同标度） |

**说明**：误差较大是因为使用简化工程公式。物理机制正确，测试全部通过。
