## 1. 案例介绍（物理背景 / 几何 / 参数）

冰晶（frazil）悬浮液的相对粘度 `eta_r(phi)` 是平台两个下游消费方（推进
推力损失 C2、可运行粘度窗口 A2）的公共输入，也是冰区 Bingham / `mu(I)`
内核的 phi-依赖项。此前仓内只有**解析闭合面**（`tensorlbm.frazil_rheology`：
Krieger-Dougherty 取 `phi_max=0.60, [eta]=2.5`，幂律指数、过冷生长窗），
**没有任何由粒子解析模拟反标定闭合的证据**。本节点补上这一段：直接模拟
硬球/近球颗粒在剪切流中的运动，测 `eta_r(phi, Re_p)`，再把三条闭合
（Einstein 稀极限 / KD / 惯性 `mu(I)` 支）与测量对表。

几何与参数（全部格点单位，`rho_f = 1`，`dx = dt = 1`）：

| 项目 | 取值 |
|---|---|
| 计算域 | 反向运动壁面 Couette 元胞，`24 x 32 x 24`（x,z 周期，y 为剪切梯度方向） |
| 壁面 | 半程反弹，物理壁面在 y=0.5 / y=ny-0.5，间隙 `ny-1 = 31` |
| 剪切率 | `gdot = U_wall/(ny-1)`，`U_wall = 0.017`（基准） |
| 载体流体 | D3Q19 BGK，`tau = 0.8` → `nu = mu = 0.1` |
| 颗粒 | 单分散球，`a = 3`（D=6），φ ∈ [0.01, 0.40] |
| 颗粒数 | 见下表 N 列（由 φ 与体积反算，确定性播撒，seed=0） |
| 颗粒动量 | 淬火（quenched）微结构：位移/转动冻结，见 §5 局限 |
| 步数 | 扫描例 900（前 300 步排除）、对照例 1200（前 400 步排除），每 10 步采样壁面动量交换力 |
| IBM | 多重直接强迫 2 遍，最多面的面标记数 10370 |
| 采样点 | φ 点 6 个、速率点 3 个、播撒重复 1 个、阻力点 2 个 |

## 2. 怎么做的（方法 / 流程 / 关键设置）

1. **测量装置**：
   * D3Q19 + Guo(2002) 力项；反向运动壁面半程反弹给出统计均匀剪切；
   * 颗粒用浸没边界（IBM）Fibonacci 面标记 + 多重直接强迫（2 遍），
     三角（trilinear）核，标记力 ∑ 守恒地摊到欧拉格点；
   * 壁面应力用**动量交换法**（MEM）测：`tau_w = |F_x| / A`；
   * **剪切率不是假设值而是测量值**：对内部速度剖面 `u_x(y)` 做最小二乘
     直线拟合得到 `gdot_meas`（剔除靠壁 2 层反弹滑移层），
     `eta_eff = tau_w / gdot_meas`，`eta_r = eta_eff / mu`。
     这消除了半程反弹的壁面滑移偏差（实测 `gdot_meas/gdot_nominal - 1 ≈
     3.21%`）。
2. **对照（control）**：同几何、同 τ、同 `U_wall` 的**纯流体**空跑，用来
   给装置定标：`eta_r(phi=0)` 必须为 1。
3. **φ 扫描**：6 个浓度点（0.02…0.40），另加
   1 个不同播撒 seed 的重复点估计构型噪声。
4. **速率扫描**：φ=0.20 固定，3 个 `U_wall`
   （→ `Re_p` 0.01…0.10），用于惯性（`mu(I)` 族）支。
5. **单颗粒阻力闸门**：周期性盒内以恒定速度拖曳单个球，测 IBM 阻力
   `C_D`，与 Stokes+Hasimoto 盒修正（Re≤1）/ Schiller-Naumann（Re>1）比。
6. **闭合标定**：Einstein 斜率（φ≤0.10 线性）、KD（`phi_max` 固定 [eta]=2.5
   的确定性由粗到细搜索 + 自由参数拟合）、惯性因子
   `eta_r = eta_r^KD (1 + C (phi/phi_max) Re_p^m)` 的对数线性拟合。
7. **插值契约**：`closure_contract()` 输出每测点的三支闭合相对误差、
   容差内判定、适用域、以及 Bingham/`mu(I)` 交接公式与**拒绝外插**清单。

审计链：每个测点一份 JSON（含 τ 时间序列、`J_xy(y)` 通量剖面、
`u_x(y)` 剖面、壁面动量平衡残差、颗粒受力），`calibration.json` 只做
聚合与拟合，报告中的数字全部由脚本注入。

| closure branch | status | points in tolerance | phi range |

契约要点（`contract.bingham_handoff`）：

* `eta_eff(phi, gdot) = mu_fluid * eta_rel_closure(phi, Re_p(phi, gdot))`
* `mu(I)` 桥：`I = sqrt(4 Re_p (rho_p/rho_f) Iv)`，`Iv = mu gdot / P`
* 屈服应力：**WITHHELD** —— 本节点没有压力控制/应力控制算例，
  给 `tau_y(phi)` 就是编造
* 拒绝区：φ 超出测量范围（jammed 外插拒绝）、`Re_p` 超出扫描范围

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **偏差异议（必须如实说）**：本节点的颗粒动量是**淬火**的
   （位移与转动都冻结）。原因是自由颗粒动力学会把 IBM 力的瞬时过冲
   （多重直接强迫尚未收敛时，约束力可比稳态阻力大一个量级）送进
   `u_p = F/(6 pi mu a)`，在高 φ 下把颗粒挤到一起后失稳（实测 NaN）。
   淬火微结构给出的是**定构型（instantaneous）应力**，其稀极限
   `[eta]` 系统性高于自由球的 Einstein 2.5 —— 见 §6 的判定。
2. **半程反弹壁面滑移**：标称剪切率与实测剖面斜率差约 3%，
   报告一律用实测斜率，否则 η 会被高估同样比例。
3. **有限尺寸**：间隙 31 格点 / 直径 6 格点 ≈ 5.2D，颗粒数 3–61；
   `chk_gap40`、`chk_radius4` 两例给出尺寸/分辨率敏感性，量化见 §3.6。
4. **IBM 力矩/力不是收敛的物理量**：只用于（已关闭的）颗粒动力学；
   应力测量来自壁面动量交换，与 IBM 力无关，因此不受该问题影响。
5. **φ=0 的对照显示装置无系统偏差**；`J_xy(y)` 剖面在流体区平坦，
   与壁面应力（乘 `(1-1/2τ)` 因子）一致，证明两套独立应力测量互校。

## 7. 结论与下一步

* 交付：可复现的粒子解析 LBM 剪切元胞 + 壁面应力/剖面双测装置 +
  `eta_r(phi)` 表 + 三闭式对照 + φ_max 拟合 + 适用域相图 +
  Bingham/`mu(I)` 插值契约（含拒绝外插与 WITHHELD 屈服应力）；
* **诚实负面结果**：淬火微结构装置**不能**复现 Einstein 2.5 稀极限
  （见 §6），因此 KD 的**幅值**不予认证（WITHHELD），只认证
  **形状参数** `phi_max`；
* 下一步（明确可执行）：(a) 给 IBM 加润滑/软排斥力并让多重直接强迫
  收敛（≥5 遍）后再开自由平动，才能拿到自由球的 `[eta]=2.5`；
  (b) 压控剪切元胞测 `tau_y(phi)` 补齐 Bingham 屈服支；
  (c) 用 Lees-Edwards 替代双壁以消除壁面 depletion 层。
