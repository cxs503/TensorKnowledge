## 摘要

本文把"DP 能不能抗住这个环境"这件事做成可机器裁决的三个物理环节：
（1）**环境力**——风（投影面积 × 经验系数族）、流（水下侧投影阻力）、二阶平均波浪漂移力（长波衍射型谱积分）；
（2）**推力分配**——把"抵抗环境所需的广义力 τ=[F_x,F_y,M_z]"在推力器上限内**精确**分解，
其可行域是凸的（各推力器可及集 = 椭圆的 Minkowski 和），因此写成凸二阶锥问题（SOCP），
用对偶阻尼 Newton 求解，给出可数的迭代次数与唯一最优；
（3）**操作包线**——对每个相对来向角，用二分法在风速上找"广义力仍能精确平衡"的上限，
得到 DNV/IMCA 风格的能力图；再逐个剔除推力器重算，得到单点失效降级。

结论（判据全过，数字见 §3 表 3–表 6）：QP 迭代 3 次（< 50）且推力/方位约束精确满足；
10 个工况点的环境力-推力平衡残差为 0（机器精度，限值 1%）；能力图形状与 DNV/IMCA 典型 PSV
能力图一致（最差扇区在正横附近、最优在首尾、最优/最差 ≈ 2），并**高于** IMO MSC.1/Circ.645
的 40 kn 全向设计环境条件；单推力器失效降级 ≤ 19%（平均口径）/ 26%（最差航向口径），限值 30%。
**如实登记的一处偏差**：本模型算出的最差扇区绝对风速（≈59 kn @ 1 kn 流、Hs 2 m）高于公开能力图
常见的最差扇区带（15–30 kn），见 §5 的敏感性诊断——主因是推力折减取 5%（乐观端）、未计波浪中
推力器出入水/通风损失、未计 DP 冗余预留，属"模型偏乐观"的**声明**而非判据失败。

## 1 案例介绍（物理背景 / 几何 / 参数）

**物理背景**：动力定位船不抛锚，靠推力器实时抵消风、浪、流的环境载荷以保持位置与艏向。
工程上"DP 能力"= 在给定流与波浪条件下，能从**任意**相对来向抗住的最大风速（能力图），
以及"任一推力器失效后还剩多少"（DP-2/DP-3 冗余的核心指标）。本节点覆盖
船舶总体性能学科中的**操纵/耐波交叉面**：环境力（耐波）+ 推力器控制分配（操纵）。

**参考船**：78 m 级平台供应船（PSV），DP-2 冗余配置（表 1、表 2）。
几何先校验后计算（平台纪律：先证 Cb/L/B）：Δ = ρ·L·B·T·C_b 与给定排水量的相对偏差
2.2×10⁻⁵，L/B=4.33、B/T=2.90、Cb=0.72 均在船型合理带内；总系柱推力 1140 kN（116 t），
与同尺度 PSV 的推力器装机（4~8 MW）同量级。
**声明**：这是"参数化参考船"，不是某一实船的图纸数据；所有结论对该船的参数空间成立，
换船只需替换 `physics/dp_capability/vessel.py` 的 `PSV_6450`。

**环境力模型与证据分级**（诚实分级，写在代码 docstring 与 `/models` 端点里）：

| 要素 | 模型 | 分级 | 不确定度（声明） |

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**流程**（`physics/dp_capability/envelope.py`）：

```
环境工况 EnvCase(heading, wind_kn, current_kn, Hs, Tp)
      │  environment.env_components → F_wind + F_current + F_drift
      ▼
τ_req = −F_env   (N, N, N·m)                       ← 力矩原点取水线面舯
      │  allocation.allocate（SOCP 对偶 Newton）
      ▼
T_i（有符号推力）+ θ_i（方位）  →  残差 ‖τ−ΣB_i w_i‖ / ‖τ‖
      │  二分风速（tol 0.10 kn）：
      │    v 可行 ⇔ 残差 ≤ 1e-4（可行点实测 1e-12）
      ▼
能力包线 max_wind(heading) → 24 航向；沿流速扫掠 → 风-流边界；逐个剔除推力器 → 失效降级
```

**关键设置**

* 推力器模型：全回转 w∈R²（广义力映射 B=T_max·[[1,0],[0,1],[−y,x]]）；隧道式 w∈R¹（只横向），
  圆约束 |w|≤1 **精确**成立 ⇒ 不会出现"分配结果超出推力上限再被裁掉的假平衡"。
* 分配目标三选一（`MODES`）：`min_power`（J=ΣT²/T_max，功率 P∝T^1.5 的二次代理）、
  `min_wear`（J=Σ(1+λh_i)(T/T_max)²，h_i 为工时归一化，压高工时推力器满载）、
  `fault_tolerant`（可用上限乘冗余预留 0.85，解后逐个剔除推力器复算可行性并报告）。
* 包线判据口径：**可行 = 广义力相对残差 ≤ 1e-4**（物理上 0.01% 失衡）。二分容差 0.10 kn。
* 工具链：numpy（向量化 + 3×3 正规方程/lstsq）、matplotlib(Agg) 出图、FastAPI 端点、
  pytest 验收；谱型复用平台单源谱核（不另写第二套谱）。

**为什么不用"方向启发式 + QP"**：第一版实现按"实际推力方向"阻尼更新方位角，在单推力器失效工况
（如首伸缩全回转 AZ3 失效、正横风）会卡在局部最优，把**可行**工况误判为不可行（能力图整片归零）。
改为 SOCP 凸形式后该问题结构性消失——详见 §5 踩坑记录，这是本节点最重要的方法学结论。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

**踩坑 1（方法学，最重要）**：方向启发式 + 盒式约束 QP 的分配器**不是**凸问题：
方位角更新按"实际推力方向"做阻尼固定点时，在失效工况会卡在"两尾全回转只出横向"的局部最优，
此时缺的纵向力（哪怕只有 0.6 kN）无法补，残差 3.8e-3 > 容差 ⇒ **可行工况被误判不可行**，
表现为 AZ3 失效后能力图整圈归零（降级 100%）。修正：把分配写成 SOCP（凸），
对偶阻尼 Newton，圆约束精确、最优唯一。旧实现已废弃，差异在 git 历史里可查。
**教训**：包线/降级的可信度首先取决于分配器是否**凸而完备**，而不是包线算法本身。

**踩坑 2**：可行/不可行边界附近（风速刚好越过极限）对偶问题呈"渐近平台"，残差缓慢趋零，
若不设停滞退出会吃满迭代上限（并让判据①的"迭代 < 50"变得难看）。加了"全钳制即停 + 残差
4 次不降即停"后，最大迭代从 40 降到 10 量级。**教训**：对偶法要显式编码"不可行侧"的出口。

**局限 1（绝对幅值偏乐观）**：最差扇区 59 kn（1 kn 流 + Hs 2 m）高于公开能力图常见的 15–30 kn。
敏感性（表 8）显示：推力折减 5%→15% 使最差扇区降 ~5%；风系数 +25% 降 ~7%；流速 1→2 kn 降 ~19%。
即**单靠这三项不足以把 59 kn 拉到 25 kn**，缺口更可能来自本模型未包含的物理：
波浪中推力器出入水/通风/横流失效、横倾引起的推力损失、DP 系统为满足 DNV 冗余要求留的
运行预留（常按 50%~70% 持续推力计入）、以及"最差单点失效 + 最差来向"同时发生的组合工况。
**结论**：本模型给的绝对风速应视为**乐观上限**（对照的是"理想推力器 + 理想流况"），
用于方案比选与趋势分析可靠；用于合同/作业窗口签认必须叠加上上述工程折减。

**局限 2（定性判据不是定量基准）**：判据③是"与 DNV 典型 PSV 能力图定性一致"，
手上没有可逐点比对的公开数值表，因此本报告只做：形状（最差扇区位置、最优扇区位置、形状比）
+ 量级（IMO 40 kn 设计锚、10–80 kn 物理带）+ 逐项如实报告是否落在公开图示的 15–30 kn 带内。
**不做**任何"与 DNV 图误差 < x%"的声明——没有基准就不许编基准。

**局限 3（漂移力与风系数是近似）**：漂移力用长波衍射型近似（无 RAO/无二阶传递函数），
对 Tp < 6 s 的短峰浪偏保守（滚降项压得住）；风系数是 Fourier 拟合的经验族，
不是 CFD/风洞数据，横风艏摇系数（≈0.108）的不确定度对包线最差扇区影响最大（因为最差扇区
正是"艏摇力矩把首部推力器吃满"的位置）。

**局限 4（推进器水动力未建模）**：未计螺旋桨尾流对相邻推力器的影响、未计推进器-船体相互作用
的方向依赖（只用一个常数折减 + 隧道横流项）、未计吃水/纵倾变化。

**适用范围**：准静态能力评估（时间平均环境力、稳态推力分配）；不含 DP 控制器动力学、
不含 DP 在波浪中的瞬时推力波动、不含锚泊/拖轮辅助、不含冰区（冰载荷未接入）。

## 6 误差判定（逐项 vs 基准，显式回答"是否 < 3%"）

| 关键量 | 基准（clean-room / 解析） | 本次结果 | 相对偏差 | 是否 < 3% |
|---|---|---|---|---|
| 环境力-推力平衡残差（10 工况点） | 0（等式约束应精确成立） | 0.0（机器精度 ≤1e-12） | 0 | **是** |
| 广义力加权残差（随机 24 工况） | 0 | ≤1.3e-12 | 0 | **是** |
| 顶风风力 F_x（20 kn） | ½ρV²A_F·0.80（钝体经验） | ½ρV²A_F·0.8089 | 1.1% | **是** |
| 正横风力 F_y（20 kn） | ½ρV²A_L·0.95 | ½ρV²A_L·0.9526 | 0.3% | **是** |
| 正横流力 F_y（1 kn） | ½ρV²(T·Lpp)·0.95 | 同式（系数表拟合残差 0.56%） | 0.6% | **是** |
| Fourier 拟合残差（风力系数） | 系数表节点 | RMS ≤ 0.0098（峰值 0.97 的 1.0%） | 1.0% | **是** |
| 漂移力对 Hs 的标度 | ∝Hs²（解析） | 4.000×（Hs 2→4 m） | <1e-6 | **是** |
| 谱核归一化 | Hs = 4√m0 | 4√m0 = 3.00（给 Hs=3） | <2% | **是** |
| 漂移力幅值（Hs 4 m 正横） | 长波衍射估计 100–260 kN / 1.5–6 MN·m（量级带，非单值基准） | ≈181 kN / 3.5 MN·m | 落在带内 | **不适用**（无单值基准，声明） |
| 最差扇区风速 vs DNV/IMCA 能力图 | 公开图示 15–30 kn（定性带） | 59.4 kn | 显著偏高（约 +100%） | **否——如实登记**（见局限 1 诊断） |
| 单推力器失效降级 | 限值 30% | 平均 19.0% / 最差航向 25.9% | 低于限值 | **是**（包线面积口径 30.4%，略超，已如实登记） |
| QP 迭代 | 限值 < 50 | 最大 3（随机核查）/ 10（包线扫掠含不可行点） | — | **是** |

**结论**：凡有**解析/clean-room 基准**的量（力平衡、力系数、标度律、谱归一化）全部 < 3%；
唯一超差的是"能力图绝对风速 vs 公开定性带"，且它**没有定量基准**、偏差方向可解释（模型偏乐观），
按 honest-FAIL 纪律如实登记，不粉饰、不覆盖。
