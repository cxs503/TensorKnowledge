# 实时 CII 轨迹追踪与纠偏航行优化（p161w2-arb-n01 / mission 10181）

## ① 案例与物理背景
以 MOERI KVLCC2 油轮（L_pp 320 m / B 58 m / T 20.8 m / Cb 0.8098 / Δ 320 420 t / 300 000 dwt，
几何取自仓内 `backend/data/geometry/ships/KVLCC2_Hull.stl` 对应标准算例）为母型，核算年 2024：
目标 CII = **2.2251 gCO2/(t·nm)**（参考线 5247·Δ^-0.61 与 Z=0.07，见证据分级），
计划航速 15.0 kn、航次 4800 nm，计划 CII = 2.3018
（相对目标 **+3.45%**，出厂即已贴线）。

物理链：`P = c_p·V³·(1+γ)`（螺旋桨定律 + 附加阻力），`φ = (P·SFOC + P_aux·SFOC_aux)/V` [gCO2/nm]，
`CII = φ/Capacity`。由此得关键结论：洁净状态下 **CII ∝ V²**，这正是纠偏优化的解析基础。

## ② 方法
1. **实时内核**（`realtime.py`）：分钟级采样 → 累计 CO2/航程 → 瞬时/累积/投影 CII；阻力因子 R̂ 与 SFOC
   用 EMA 做数据同化，投影一律用"持续性预报"（不偷看未来气象）。
2. **目标轨迹与偏差带**（`target.py`）：`M_allowed(t)=CII_target·Capacity·D(t)`，δ = CII_cum/CII_target − 1；
   偏差带 ±5% 可配置，预警用**投影终值偏差**（前瞻，避免早期噪声）。
3. **预警与根因**（`alert.py`）：黄 3% / 红 5% + 0.5 个百分点滞环 + 起步 2% 航程的 WARMUP 门控；
   根因用**链式**与**LMDI-I** 两条独立可闭合分解（速度/环境/机况/燃料/辅机）。
4. **纠偏优化**（`correction.py`）：`min|CII_final−CII_target|` s.t. ETA 窗口、航速包络、MCR 上限；
   λ-KKT 解析解 `V_i=((a_i+μ)/(2k_i))^{1/3}`（均匀态退化为单变量闭式），并以时间网格 DP 与 SLSQP 独立校验。
5. **闭环仿真**（`simulate.py`）：环境（风暴前沿 30% 加阻）→ 测量噪声（功率 1.5%/航速 0.3%）→ 追踪 →
   预警 → 每 6 h 滚动重解（MPC）→ 航速反馈。baseline 与 MPC 用**同一随机种子**，同扰动对照。

## ⑤ 注意点与局限
1. **SFOC 负荷曲线与功率标定点是假定参数**（未做实船台架标定）→ 该层 WITHHELD；
   绝对排放数不得作实船认定，结论限于**算法正确性与同扰动相对改进**。
2. **目标 CII 依赖转录规则系数**（MEPC.353(78)/338(76)），离线不可回读原文 → WITHHELD；
   2027+ 自动标 `z_extrapolated`，2019 及以前仅参考线口径。
3. **单项偏离时链式与 LMDI 恒等**（差异 0），多因子叠加时两者分配不同（上表第 4 行已给出具体差值）；
   报告选择链式为主口径、LMDI 为对照，两者均精确闭合。
4. 投影用**持续性预报**（R̂ 不变）——比"完美气象预报"更保守也更诚实；真实船舶应接气象预报场。
5. 航线改变未纳入决策空间（只调航速）；`recommendations` 给出航线/纵倾/清洗等方向性建议。
6. 均匀 γ 时 λ-KKT 与闭式解逐位一致（1e-16）；非均匀 γ 时 DP 因时间桶离散略差 ≤0.42%。
