## 方法与不可越过的事实

- **零手抄**：所有 markdown 定位符由程序 `find` 出 `char_start/char_end` 并回读断言 `source[start:end] == quote`，找不到即抛错；6 条 markdown 定位符全部逐字成立。
- **附件可达性是被测出来的，不是假设的**：`/tensor/reports/771/figures` 与逐张 `/figures/<name>` 均返回 HTTP 404，故 3 张图登记为 `unresolved`（只存文件名与记录字段，caption 与文件名相同，无独立描述）。
- **正文引用的工件无字节副本**：`src/tensordem/granular_dem.py`、`examples/hopper_beverloo_case.py`、`hopper_beverloo_report.py`、`outputs/*.json`、`CASE.md` 只登记「引用存在」，owner 在 TensorDEM 仓；下游需要内容必须回产出仓取，不得从 manifest 推断。
- **登记 ≠ 验证**：`verification.performed=false`，manifest 中无任何 `verified` 字样；verification 由平台门计算。
- **零抽取**：`extraction.performed=false`、`claims_registered=0`；报告中的 Beverloo 数值与 AOR 失败结论未进入本产物。
- **定位符偏移约定**：`char_start/char_end` 是 markdown 字符串的 **Unicode 码点偏移**（Python `str` 下标），不是字节偏移；同时提供逐字 `quote`，因此忽略偏移、只做子串校验的检查器也会落到同一段文本（`tests/test_kf_wp771_01_asset_manifest.py::test_locators_are_self_consistent_without_byte_offsets` 守着这一点）。
- **待上游确认**：记录 `mission_id=813` 与契约 `mission_id: null` 不一致，已按观察值登记，未擅自归一。
- **schema 文件来源**：本检出原本缺 `schemas/kf_result.v1.schema.json`，为让 schema 门可执行，取同平台兄弟检出的逐字节副本（sha256 `170dba8b0b5d54012490aaadc0b68647a9520ecb869e9d03f873afb99b74c076`）；若上游有权威版本以权威版为准。
