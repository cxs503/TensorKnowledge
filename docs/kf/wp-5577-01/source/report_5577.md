## ① 案例介绍

**物理背景**：示范算例为 KRISO 公开基准船 KCS 集装箱船的静水裸船体阻力预报。总阻力按
R_T=(1+k)R_F+R_W+R_B+R_TR+R_A+R_APP 分解，兴波阻力取 Holtrop & Mennen (1982) /
Holtrop (1984) 回归 R_W = c1·c2·c5·∇·ρg·exp(m1·Fn^d + m2·cos(λ·Fn^-2))，d = -0.9。
该式对 Fn 呈强非线性（m1·Fn^-0.9 在指数上），故任何"按 Fn 分段的多项式"近似都会在中等
Fn 段产生成倍偏差——本单发现的缺陷即源于此。

| 量 | 值 | 单位 |
|---|---|---|
| Lpp / B / T | 230.0 / 32.2 / 10.8 | m |
| ∇ | 52030 | m³ |
| Cb / Cm / Cwp | 0.6509 / 0.9849 / 0.7630 | — |
| 设计航速 / Fn | 24.00 / 0.2600 | kn / — |
| 几何先验（Cb 反算偏差） | 0.0617（<1% 通过） | % |

## ② 怎么做的

一条命令 `python -m bp_demo.run` 复跑四阶段闭环，每阶段留 sha256 证据：

1. **任务组织**：平台任务池快照（上限 200 条）→ 战役节点 / 执行者 / 状态分布；
2. **引擎调用**：从本工作树起临时 uvicorn（8103，跑完即关停），对
   `/api/v1/calculations/resistance` 发 5 航速 + 2 条负控（∇ 偏 8%、Cb=1.4 → 必须 422）
   + 1 次确定性复调；
3. **算力管理**：`cluster_exec.py nodes` 探活 外协方双节点 loong64，失败回落冻结快照；
4. **独立验证**：ITTC-57 闭式复算、系数场自洽、单一物理源对标、KVLCC2 文献锚点、pytest；
5. 渲染 3 图 + 报告 → 过六要素报告门（report_gate）。

**本轮修复**：端点 Cr 原为 `Cr = 0.005·C4(Fn)·C1·C2·C3` 分段多项式 mock；改为
Cr = R_W(V)/(½ρV²S)，R_W 直接调 `physics/holtrop` 单一源（不复制经验公式）；另把缺省
Cwp 从 `0.75+0.25Cb`（KCS 给 0.913，实船 0.763）改为 Momo/Schneekluth 回归 (1+2Cb)/3
（KCS 0.767、KVLCC2 0.873）。

## ⑤ 注意点

- **同仓两套阻力链**：`/calculations/resistance`（旧 mock）与 `/resistance/predict`
  （Holtrop 主链）并存，m2082 并一只并主链 → 必须做跨端点同点一致性回归；
- **部署漂移**：常驻 8002 是旧构建，同点仍返回 7401.24 kN；修复需重新部署
  才对外生效，本报告数字取自工作树临时实例；
- **既有用例腐化**：tests/test_resistance_ittc78.py 因符号 `_legacy_cr_mock` 移除、
  `physics.holtrop` 缺 backend 路径而整文件收集失败；本轮补路径 + skipif 守卫后
  41 passed / 3 skipped；
- **局限**：端点无 (1+k)/附体通道，与含形因子的全尺度数据对标系统性偏低约
  17.3%；未取得 KCS 水池试验原始数据表，单一源对标属同级而非
  实验对标；Cwp/Cm 缺省仍为估算，非常规船型不适用；Holtrop 适用域 Fn 0.10–0.45。
