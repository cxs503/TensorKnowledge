## ① 案例介绍（物理背景 / 几何 / 参数）

对象是船舶绿色航行-冰区域求解链上的**航线优化层** `modules.green_navigation_ice.route`：
"A2 冰情场 → 冰阻力与推进链（W3-N11）→ 冰中可达航速/油耗 → IMO MSC.1/Circ.1519 POLARIS 风险指数
+ B2 结构载荷包络 → GO/CAUTION/NO-GO 分区 → 8 邻域网格 A*"。代价为三目标加权和

$$J = w_E\,\frac{E}{E_{ow}} + w_T\,\frac{T}{T_{ow}} + w_R\,\frac{R}{\Delta s_{gc}}$$

NO-GO/LAND 是硬约束（删边），CAUTION 进入风险代价。基准冰场为理想化喀拉海走廊
（57×31 格，格距 9.61×10.07 nm），
起点 [68.6, 57.5] → 终点 [72.2, 83.0]；船型 `arctic_bulker_45`（PC6，Cb 几何自校验 PASS）。

本节点的作用域是**测试面**（战役规定"只补测试不改算法"）：把 D1 交付的求解器在边界工况、
非法输入、可复现性三个方向上压实。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **"零和权重"不是无害输入**：`0·inf = nan` 污染不可通行边的代价数组，"最小代价"退化为搜索顺序上的
   第一条可行路径（近似跳数最短路），结果看起来完全合法。第二刀把它变成显式拒收。
2. **NaN 能绕过范围检查**：`np.any(arr < 0)` 对 NaN 恒假；冰厚/密集度的 NaN 会静默流入插值和边代价，
   因此闸门用 `isfinite` + 上下界两段判据。
3. **闸门是拒收不是裁剪**：边界值（h=20 m、T=−60 ℃、C=1）必须放行，另有专门测试防过度拒收。
4. **局限**：基准冰场是理想化构造（非 A2 观测产品），回归锁只锁"同一构造下的同一解"，不构成对真实冰区
   的绝对正确性主张；走廊是 9×15 玩具网格，用于拓扑判据而非标定绕行代价量级；`figures.py`/`run_route.py`
   脚本层不在"新增逻辑"覆盖口径（0%），其行为由工件存在性测试覆盖。
5. **D1 边界**：本节点不引入新求解算法；若 D1 分支后合入主干，三处闸门（注释含 `IN16-K9`）可机械重放。

## ⑥ 误差判定（逐项回答"是否 <3%"）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 权重齐次标定（×10）后航线摘要 | 原摘要 | 0（逐位一致） | **是** |
| 单目标解 vs balanced 解（自身目标） | balanced | 0.000%（min_* ≤ balanced，越界即失败） | **是** |
| 回归锁 sha256（4 条航线 + 合计） | 锁文件 | MATCH（逐位） | **是** |
| 走廊航线长度 vs 起点→缺口→终点大圆下界 | 148.848 nm（解析） | 8.620% | **否**，且不应如此要求 |

对最后一项的显式说明：走廊航线按 8 邻域对角线行走，长度必然大于分段大圆下界（本测例
8.62%），这是**网格离散度量**而非物理模型误差；判据因此定义为
"≥ 解析下界（不可能更短）且 ≤ 下界+15%"，而不是假装满足 3%。真正可做 <3% 判定的三条数值项
（齐次标定一致、单目标不劣、回归锁逐位）全部通过。
