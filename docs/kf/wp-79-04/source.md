**流程**：
1. 登录平台获取 JWT token
2. GET 三篇报告全文

4. 数字溯源抽查（每篇 3 个关键数字）
5. 生成质检文档 `docs/qa_batch_64_65_66.md`
6. POST 质检汇总报告
7. 对 RESUBMIT 篇目派返工单

## ⑤ 注意点

**踩过的坑**：
1. 平台 API 端口差异：`call_ship_api` 默认连 8001 端口，但 tensor/reports 端点在 8010 端口，需用 python urllib 直接调用
2. 图件嵌入格式：figures 数组需含 `png_base64` 字段，仅有 `name` 和 `caption` 不足以嵌入图片
3. 数字溯源精度：工件 JSON 中的浮点数精度高于报告中的舍入值，需用近似匹配（±0.01%）

**局限**：
- 仅抽查 3 个数字/篇，未覆盖全部数据点
- 图件检查依赖工作目录文件搜索，未验证 API 返回的 base64 数据

## ⑥ 误差判定

本任务为质检审核，无计算误差。质检判定依据：
- 数字溯源误差 < 0.01%（舍入误差范围内）
- 结构完整性：逐节检查
- 图件可用性：文件存在性 + base64 嵌入检查
