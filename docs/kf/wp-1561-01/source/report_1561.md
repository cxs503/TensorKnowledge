## ① 案例介绍

**物理背景。** 船舶快速性链条上有两个必须闭合的量：阻力侧给出 R_T·V（有效功率 P_E），
推进侧交付 T·(1-t)·V 与 P_D=2πnQ；同一船同一工况下必有

```
T·(1-t) = R_T          （推力平衡，t 为推力减额）
P_D      = P_E / η_D   （功率平衡，η_D = η0·η_H·η_R）
```

平台两端点各自"自证"多年（阻力 m1536/m1771/m1773、推进 m1498/PB-009），却从未被放在
同一工况上对账。m1818 建了跨端点闸门（tools/chain_gate，判据 I1–I6），在 5 型船上实跑
暴露：`/propulsion/predict` 给出的推力只有需求带 R_T/(1-t) 的 24.7%–67.5%，交付功率缺
14.7%–68.8%，交叉有效功率比 T(1-t)V/(R_T·V) 仅 0.220–0.600。

**根因（读码定位）。** 旧 `/propulsion/predict`（backend/api/propulsion.py 上一版）：

```python
Dp = 0.7*T*0.8 ; n = V/(Dp*0.7)        # 转速由航速"抛出"，与阻力无关
Kt = 0.3 - 0.2*J ; Kq = 0.04 - 0.02*J  # 两条经验直线
```

转速不含任何阻力信息 ⇒ 推力与 R_T 结构性失配；且 Kq 在 J=2 处归零时 Kt 仍为正，
η0=J·Kt/(2πKq) 在低 J 段发散——这是任何钳位都掩盖不了的结构缺陷。

**算例。** 闸门内置 5 型船（宽覆盖 Cb 0.62–0.82、Fn 0.13–0.26），几何与参数如下
（与 `tools/chain_gate.SHIPS` 逐字一致：KCS / KVLCC2 为国际标模，Feeder120 / Aframax /
Ferry 为参数化代表船型）：

| 船 | L_wl[m] | B[m] | T[m] | Cb | ∇[t] | V[kn] |
|---|---|---|---|---|---|---|
| KCS | 230.0 | 32.2 | 10.8 | 0.651 | 52030 | 15.0 |
| KVLCC2 | 320.0 | 58.0 | 20.8 | 0.8098 | 320000 | 15.5 |
| Feeder120 | 120.0 | 19.0 | 7.0 | 0.70 | 11000 | 14.0 |
| Aframax | 250.0 | 44.0 | 14.5 | 0.82 | 115000 | 14.5 |
| Ferry | 160.0 | 26.0 | 6.0 | 0.62 | 16000 | 20.0 |

## ② 怎么做的

**新内核 `backend/modules/propeller_bemt.py`（叶片元 + 轴流动量，BEMT）。**
以诱导速度 (u_a, u_t) 为未知量逐半径配平（以诱导速度而非诱导因子为未知量，J→0 的
系泊工况仍有定义）：

```
叶元推力 = ½ρW²·Z·c·C_n = 4πρr·u_a(V_a+u_a)·F      （动量推力）
叶元扭矩 = ½ρW²·Z·c·C_t·r = 2πρr(V_a+u_a)·2u_t·F·r  （角动量通量）
```

* 剖面：Cl = 4.3·(α−α₀(x))，α₀ 从梢部 −2° 到根部 −5°（弯度向根部增大）；
  摩阻按 **ITTC-78 桨叶剖面摩擦线** Cd_f(Re)=2(1+2t/c)[0.044Re^(−1/6)−5Re^(−2/3)]，
  总阻 Cd = Cd_f + 0.022·Cl²，12° 失速平台；
* 弦长按 B 系列形状 c(x)=0.55+1.5x−1.05x²，幅值由盘面比定（Σc·Z·R·dx = Ae/Ao·πD²/4）；
* Prandtl 梢/毂损失因子 F；径向 12 站中点法则积分（12→32 站 K_T 差 0.6%、η0 差 0.05%）；
* 敞水量 K_T=T/(ρn²D⁴)、K_Q=Q/(ρn²D⁵)、η0=J·K_T/(2πK_Q)；守恒性保证 η0 ≤ η_I=2/(1+√(1+C_T))。

**推力闭合反解（不用钳位）。** 给定 R_T（由**与 /resistance/predict 同一套 Holtrop 输入**
算得，保证两端点同源），需求推力 T_req = R_T/(1−t)。T(n)=K_T(J(n))·ρn²D⁴ 在 (0,∞) 单调
递增（n↑ ⇒ n²↑ 且 J↓ ⇒ K_T↑），故用对数区间二分解 T(n)=T_req，收敛后再以精确 BEMT 点
重算 K_T/K_Q/η0，报告量不含插值。

**设计自由度（不是截顶）。** ①桨径：单桨尾型取 D/T=0.70（闸门 I5b 允许 0.40–0.75，
取 0.70 留余量）；依据是定推力下桨径越大盘面负荷 C_T 越小、η0 单调上升（图 3，测试断言）。
②螺距比：P/D 扫掠（0.6–1.3 网格 + 半步长细化）取 η_D 最大者（图 5）。二者都是设计选择，
选定后推力仍由转速反解闭合。

**端点改造 `backend/api/propulsion.py`。** 响应契约保留 `thrust/efficiency/power/
propeller_diameter/propeller_rpm`（`power` 明确为交付功率 P_D），新增 `thrust_required/
resistance_total/effective_power/torque/pitch_ratio/n_rps/advance_ratio/kt/kq/
eta_open_water/eta_hull/eta_rotative/thrust_deduction/wake_fraction/ct_loading/eta_ideal/
equilibrium_error/geometry_check/design/method`；非法入参 422（不把数截进区间），
几何不自洽（Cb·L·B·T 对排水量偏差 >10%）在响应里显式报告。

**验证链。** ①pytest 28 项（含直接调用闸门谓词 I2/I3/I4/I5/I5b/I5c、无钳位性、致动盘上界、
径向收敛、桨径单调、入参门禁）；②闸门实跑：修复前 :8001 与修复后自建 :8099 各跑一遍
（同一份 `chain_gate --live`，同一组 5 型船）。

## ⑤ 注意点（踩过的坑与局限）

1. **Ferry 落在 I3 带边上（η_D=0.516）**。该船 R_T 由阻力端点给出 1457 kN（20 kn，
   Fn=0.26，总阻力系数 C_t≈0.0077，波阻占 68%），盘面负荷 C_T=4.37，
   属重载桨；即便 D/T 取到 0.70、P/D 最优化，η_D 也只能到 0.51。若阻力端点的绝对精度日后被
   修正（R_T 下调 20%），η_D 约升 0.04（η_D 对 R_T 的弹性约 −0.2）。这是**跨域耦合的真实风险**，
   不是推进端缺陷。
2. **模型绝对精度未经实验标定**。剖面极曲线是二维翼型工程近似 + ITTC-78 摩阻线；与固定几何
   B4-70 实测谱相比，重载端（C_T>3）模型偏乐观（同 C_T 下 η0 高约 15–20%），因为它隐含
   "为工况设计过的桨"（本模块的确在做设计扫掠）。因此功率绝对值的模型不确定度约 ±10–15%。
3. **t、w 用单桨 Taylor 式**（t=0.5Cb−0.12，w=0.5Cb−0.05），Cb>0.85 或双桨/吊舱不适用；
   调用方可显式传 t/w/η_R 覆盖。η_R 默认 1.0（偏保守：Holtrop 回归值约 0.98）。
4. **几何自洽性逐船报告**（>10% 偏差显式标注，不静默放行）：
- **KCS**：Cb·L·B·T=52070 m³，输入排水量=52030，偏差 -0.1%
- **KVLCC2**：Cb·L·B·T=312622 m³，输入排水量=320000，偏差 +2.4%
- **Feeder120**：Cb·L·B·T=11172 m³，输入排水量=11000，偏差 -1.5%
- **Aframax**：Cb·L·B·T=130790 m³，输入排水量=115000，偏差 -12.1%（>10%：吃水/方形系数与排水量不自洽，请核对是否为设计吃水）
- **Ferry**：Cb·L·B·T=15475 m³，输入排水量=16000，偏差 +3.4%
   其中 Aframax 的 Cb·L·B·T 与输入排水量相差 13.7%，提示 T=14.5 m 为结构吃水、排水量对应
   设计吃水——资源端应予校正；本端点按请求值计算并在响应中标注。
5. **性能**：单次 /predict 约 4–6 s（P/D 扫掠 10 次 BEMT 反解），闸门 5 船一次 ~25 s；
   闸门 HTTP 超时 30 s，目前留有裕度但不宜再加扫掠点。
6. **旧 /design 接口（Wageningen B 回归 + max/min 截断）未改动**，属后续清理项：它的
   K_T 上下限钳位与本次"禁钳位"原则冲突，但它不在闸门闭环链上。

## ⑥ 误差判定（逐项，并显式回答"是否 <3%"）

| 关键量 | 基准 / 判据 | 实测 | 是否 <3% |
|---|---|---|---|
| 推力闭合 T(1−t) vs R_T | **恒等式**（零模型假定） | 残差 ≤ 1.11e-05 | **是**（<1e-5） |
| 跨端点 R_T 同源（推进内部 vs 阻力端点） | 同一 Holtrop 输入 | 相对差 <1e-6 | **是** |
| I2 推力落在 R_T/(1−t), t∈[0.10,0.30] | 物理区间 | 5/5 PASS | **是** |
| I3 功率落在 P_E/η_D, η_D∈[0.50,0.78] | 物理区间 | 5/5 PASS（η_D 0.516–0.625） | **是** |
| I4 交叉比区间含 1.0 | 恒等式 | 5/5 PASS | **是** |
| I5/I5b/I5c（K_T、D/T、J 合理性） | 物理区间 | 5/5 PASS | **是** |
| 径向离散收敛（12 vs 32 站） | 自收敛 | K_T 0.6%、η0 0.05% | **是** |
| η0 vs B4-70 实测谱（固定几何，同 C_T） | 实验谱 | 重载端偏乐观 15–20% | **否**（见注意点 2；无实验数据离线可得，故不作"通过"声明） |
| 已有能力 vs 实验基准（阻力 R_T 绝对值） | 实验/参考船 | 未判定（属阻力域） | **未判定**：本单不改阻力；Ferry 的 C_t≈0.0077 偏高，是 η_D 贴带的根因 |

**总判定**：闸门 `verdict_fail=0`（5 型船 × 7 条判据），推力/功率/交叉比三条判据全部由
T(1−t)=R_T 反解转速得到，未使用任何钳位或常数截顶；报告如实标注 Ferry 的带边风险与
BEMT 重载端相对实测谱的乐观偏差。
