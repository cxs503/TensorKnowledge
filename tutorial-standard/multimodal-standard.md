# Multimodal Learning Standard

## Purpose

Use multiple forms of representation to deepen understanding of a shared phenomenon, concept, or system. Multimodality is a learning strategy, not a requirement to attach media to every page.

## Possible modalities

Natural language; mathematical notation; tables and charts; diagrams and maps; source code and notebooks; images, animation, audio, and video; physical demonstrations; simulation outputs and interactive models.

## Minimum quality requirements

1. State what media represents and what it does not represent.
2. Label axes, units, scales, coordinate frames, and relevant parameters.
3. Identify whether a result is observed, measured, simulated, inferred, or illustrative.
4. Provide captions, transcripts, alt text, or text equivalents where appropriate.
5. Record data and media provenance, license, and transformations.
6. Avoid visualizations that imply unsupported precision or causality.
7. Ensure examples can be understood without relying on color alone.

## Translation activities

Ask learners to explain a mathematical relationship in plain language; infer a trend from a graph and identify uncertainty; connect a simulation field to governing variables; compare an image or video with measured data; or identify information lost when changing representation.

## Reproducibility

For generated plots, simulations, and notebooks, record code, software versions, parameters, input data, and execution instructions when feasible. If exact reproduction is not possible, state why.
