## 2. 三场景与命题-证据映射

### 场景一 · 科学命题（低风险有界）

**`tkc:prov-o:wasattributedto-signature`**（definition / asserted / **established**；条件域=仅对 REC-prov-o-20130430 文本成立）

> W3C PROV-O（REC 2013-04-30）中，prov:wasAttributedTo 定义句为 "Attribution is the ascribing of an entity to an agent."，是 prov:wasInfluencedBy 的子属性，domain=prov:Entity，range=prov:Agent。

| 证据 | 关系 | 定位 |
|---|---|---|
| `tke:prov-o:entry6-wasattributedto` | supports | §4.1 Starting Point Terms 交叉引用条目 (6) Property: prov:wasAttributedTo（定义句+super-properties/domain/range 逐字） |
| `tke:prov-o:section31-agent-responsibility` | contextualizes | §3.1 叙述段："An Agent's responsibility for an Activity or Entity is described using the properties prov:wasAssociatedWith and prov:wasAttributedTo, respectively." |

## 6. 局限、未决与诚实披露

1. **FAIR 原始论文未直接核验**：证据引的是 go-fair.org 社区呈现页，非 Wilkinson et al. 2016 Scientific Data 原文。原则文本公认一致，但按铁律这一层差异必须披露；窄命题 C3 的 note 已内嵌此局限。
2. **无独立评审**：全部 epistemic_status 为生产者自标（established/contested/well-supported/not-assessed 仅反映文本可核验性判断）；7 号判据的「可核验性」成立但核验本身未发生。
3. **实现状态裁定未做代码审计**：场景三结论 not-assessed 的边界=未扫全仓代码；如需升级为确认/否定需补代码级证据。
4. **单会话单读**：引文核对=抓取当场目视比对，无第二读者；webReader 为中间层（markdown/text 转换），非浏览器 DOM 原文，极低概率存在转换伪影。
5. **go-fair 页面为活页**：captured_at=2026-11-09 锚定；页面变更后引文以抓取时点为准。
6. **评审工时估计**：独立评审者核验 8 个定位（3 个 URL 直达）+ 判 4 条蕴含 + 复跑 3 个验证器 ≈ **30-45 分钟**。
