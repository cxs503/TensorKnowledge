# TensorKnowledge Pilot Programs

Pilot programs are controlled tests of the knowledge architecture and learning methodology. A published design brief is not evidence that a pilot has been run.

## Current pilot

- [Cross-disciplinary learning pilot](cross-disciplinary/README.md) — four studios spanning scientific inquiry, engineering design, humanities research, and creative production.
- [Machine-readable work-package manifest](cross-disciplinary/pilot-work-packages.json) — proposed packages TK-008–TK-014, with dependencies, deliverables, and reviewer requirements.

Learner participation requires appropriate consent, privacy protections, accessibility arrangements, and any applicable institutional approvals.
